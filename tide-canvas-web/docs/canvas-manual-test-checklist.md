# 核心画布手动验收清单

适用范围：`/canvas/*`。本清单用于本次 React Flow 迁移和生产化解耦的人工回归；不包含画布外页面的
业务验收。

## 1. 测试准备

- 准备一个空项目、一个包含常用节点的小项目、一个接近 500 个混合媒体节点的大项目。
- 小项目至少包含：文本、图片、视频、音频、角色、场景、3D 场景、分组、普通连接、多输入连接。
- 准备合法图片和视频各 2 个，以及超限/错误格式文件各 1 个。
- 准备可正常生成、生成失败、长时间生成中的模型配置。
- 浏览器控制台保持打开；测试期间不得出现未处理异常或持续重复请求。
- 在测试前记录项目 revision 和 `canvasData`，用于确认兼容与失败恢复。

## 2. 浏览器与设备矩阵

每个“核心”项目至少在以下环境各跑一次第 3～8 节：

- Chrome 当前版与前一主版本；
- Edge 当前版与前一主版本；
- Safari 当前版与前一主版本；
- Firefox 当前版与前一主版本；
- 现代 iPadOS Safari，横屏和竖屏各一次；
- macOS 触控板或等效高精度触控板；
- 鼠标（含中键和滚轮）。

不验收 IE、旧版浏览器或低版本 iPadOS。

## 3. 加载、保存与兼容

- [ ] 直接打开已有 `/canvas/{token}`，标题、缩略图、节点、连接、分组和媒体均正确恢复。
- [ ] 刷新页面，位置、尺寸、提示词、模型参数、组图当前结果等数据不丢失。
- [ ] 修改节点后等待约 3 秒，保存状态先变为保存中，再显示已保存。
- [ ] 连续快速修改多个节点，在途保存结束后仍会补一次最新保存，不丢最后一次修改。
- [ ] 保存响应丢失但服务端已提交时，页面通过权威读取识别为已保存，不重复覆盖。
- [ ] 同一项目开两个窗口并产生 revision 冲突，后保存窗口暂停自动保存并提示冲突。
- [ ] 关闭/切换路由前有待保存内容时会触发冲刷；重新打开后内容存在。
- [ ] 上传中的 `blob:` 临时地址不出现在服务端 `canvasData`。
- [ ] 在一份测试 JSON 中加入未知顶层字段，打开并再次保存后该字段仍存在。
- [ ] 在测试 JSON 中插入一个损坏节点、悬空连接和空分组：有效内容仍加载，坏记录被隔离，页面不白屏。
- [ ] 打开旧 `skillRunState` 数据后能恢复；再次保存使用当前 `skillRuns` 字段。

## 4. 视口、鼠标与触控板

- [ ] 鼠标拖动空白区域可平移，节点不被误选或误拖。
- [ ] 中键拖动画布可平移。
- [ ] 触控板双指滚动平滑平移，不意外缩放。
- [ ] 触控板捏合可缩放，中心点稳定，无明显跳变。
- [ ] 工具栏放大、缩小、100% 重置、适配视图均正确，动画克制且无抖动。
- [ ] 最大和最小缩放受限，不能无限放大或缩小。
- [ ] 开启网格吸附后节点按 20×20 网格移动；关闭后自由移动。
- [ ] 打开缩略图后可点击/拖动定位，缩略图颜色与节点类型对应。
- [ ] 右键菜单出现在指针处；缩放和平移后新建节点落点仍准确。
- [ ] 拖入文件时遮罩出现，离开画布后消失，放下后节点出现在落点附近。

## 5. 选择、拖动、键盘与分组

- [ ] 单击节点只选中该节点；单击空白清空节点和连接选择。
- [ ] `Control`（Windows/Linux）或 `Command`（macOS）可增量多选。
- [ ] 按住 Shift 在空白处拖动可框选，部分相交节点按当前 Partial 规则选中。
- [ ] 多选节点拖动时相对位置不变，撤销只回退一次完整拖动。
- [ ] Delete/Backspace 删除普通选中节点；生成中或可恢复任务节点不会被误删。
- [ ] 复制、粘贴、全选、撤销、重做快捷键不在输入框/文本域内误触发。
- [ ] 节点内部输入、按钮、下拉、滑块、链接、音视频控件可操作，不拖动节点。
- [ ] 两个及以上节点可创建分组；分组标题、颜色和边界正确。
- [ ] 拖动分组时所有成员同步移动；触摸拖动时页面不跟随滚动。
- [ ] 从分组移除节点、删除分组但保留节点、删除分组及节点均符合原行为。
- [ ] 自动排列后连接关系不变，并自动适配新布局。

## 6. 连线与快捷创建

- [ ] 从输出手柄拖到输入手柄可创建连接，方向与端口槽位正确。
- [ ] 不能连接到自身；重复连接不会新增第二条。
- [ ] 连接在节点移动、缩放和节点尺寸变化后仍贴合端口。
- [ ] 点击连接可选中，Delete/Backspace 可删除，撤销可恢复。
- [ ] 选中相关节点时连接高亮；高亮动画不阻塞交互。
- [ ] 从端口拖到空白处超过阈值会打开快捷新增菜单。
- [ ] 快捷新增节点位于释放点并自动连回源节点；取消菜单不产生节点或连接。
- [ ] 触摸操作时连接手柄命中容易，不因手指轻微移动直接取消。

## 7. 节点与媒体

- [ ] 文本、图片、视频、音频、角色、场景、3D 场景等节点外观和原功能未改变。
- [ ] 图片上传、替换、下载、复制、裁剪、旋转、翻转、宫格切图可用。
- [ ] 图片比例、清晰度、质量、批量数量、模型和风格选择可用，弹层定位正确。
- [ ] 组图切换和主图保持正确；刷新后只保留正式远端地址。
- [ ] 全景图查看、内嵌全景交互和关闭流程可用。
- [ ] 视频播放、暂停、首尾帧/参考素材配置和下载可用。
- [ ] 音频播放、分轨切换、延长/翻唱原曲选择和上传登记可用。
- [ ] 3D 节点加载时不阻塞普通节点操作，卸载/切换后无持续渲染错误。
- [ ] 单个节点组件故障时仅显示节点错误态，其余画布仍可编辑。

## 8. AI 生成、助手与快速启动

- [ ] 空提示词、缺参考图、缺首帧、缺原曲等请求在前端被阻止，不产生付费任务。
- [ ] 正常图片/视频/音频/文本生成进入生成中并最终正确回填对应字段。
- [ ] 同一节点生成中重复点击不会创建第二个任务。
- [ ] 创建请求响应不确定时显示“正在确认”，用同一 `clientRequestId` 恢复，不重复扣费。
- [ ] 生成中刷新页面，已有 `taskId` 继续轮询并最终回填。
- [ ] 只有冻结请求但未取得 `taskId` 时，刷新后能取回同一任务。
- [ ] 临时断网或网关错误不会把任务立即标记失败；恢复网络后继续确认。
- [ ] 明确失败/取消任务恢复为正确节点状态，已有旧结果不会被清空。
- [ ] 新一轮生成或上传发生后，旧任务结果不能覆盖新结果。
- [ ] AI 助手聊天、附件引用、技能选择、运行历史恢复和产物落盘可用。
- [ ] 从其它页面携带合法 handoff 进入画布只执行一次；过期、跨用户或跨项目 handoff 被拒绝。
- [ ] 快速启动的模型、比例、质量、引用限制和稳定提示词映射与改造前一致。

## 9. 触摸与 iPadOS Safari

- [ ] 单指点选节点，节点内部按钮和输入正常获取焦点。
- [ ] 双指平移和捏合缩放顺畅，不触发页面橡皮筋式滚动干扰。
- [ ] 长按/拖动节点、端口连线、拖动分组不会出现鼠标专属逻辑失效。
- [ ] 横竖屏切换后画布尺寸、浮层位置、快捷菜单和工具栏重新布局正确。
- [ ] 软键盘弹出/收起后输入框仍可见，关闭弹层后画布手势恢复。
- [ ] Safari 返回前进缓存恢复后没有重复轮询、重复保存或失效的事件监听。

## 10. 500 节点性能与稳定性

- [ ] 首次打开大项目可以完成，不出现浏览器“页面无响应”。
- [ ] 视口外节点未大量挂载；平移时节点按需出现，不持续闪烁。
- [ ] 单节点文本编辑、选择或状态变化不会让全部媒体节点重新加载。
- [ ] 连续平移、缩放、框选和拖动 2 分钟，无明显持续性帧率下降。
- [ ] 打开/关闭缩略图、历史、资产、助手面板后内存不会持续单向增长。
- [ ] 删除大量节点、撤销重做、切换项目后旧媒体播放和生成轮询停止。
- [ ] 保存请求频率符合防抖设计，不因拖动产生每帧网络请求。

## 11. 错误、监控与发布门禁

- [ ] 注入监控 sink 后，保存成功/失败/冲突、文档恢复、错误边界事件可收到。
- [ ] 监控属性不包含提示词、token、完整画布 JSON 或完整媒体 URL。
- [ ] 不配置监控 sink 时所有流程正常，不抛异常。
- [ ] 控制台无未处理 Promise、React key、受控/非受控、事件监听泄漏错误。
- [ ] `npm audit` 为 0 漏洞。
- [ ] `npm run typecheck` 通过。
- [ ] `npm run lint` 为 0 错误。
- [ ] `npm run build` 通过。

验收人应记录浏览器/系统版本、项目 token、失败步骤、控制台信息和最小复现。所有核心项通过后方可合并。
