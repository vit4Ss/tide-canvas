# AI 平台适配导入

入口：后台 → 技能管理 → 导入 Skill。默认勾选「AI 适配本站能力」，本地文件、目录、ZIP 和 GitHub 来源均使用同一流程。

没有新增前台“我的技能”或普通用户发布接口。持有现有后台技能管理权限的使用者，仍在同一个导入弹窗操作；原有上架、对外开放和站内使用规则保持不变。

## GPT 内容整理

对于尚不规范的 GPT 输出，在来源区域展开「GPT 写的内容还不是标准 Skill？在这里整理」，可直接粘贴文字或选择 1 MB 内 `.md/.txt` 草稿（最多 10 万字）。这是显式的创作整理入口，和标准文件包导入分开：普通文字只作为原始资料保存，模型必须生成新的标准 Skill 和可执行配置，通过后端校验并确认后才能导入。

点击「读取并 AI 整理」或选择 GPT 文本文件后，会沿用现有单 Skill 的自动 AI 配置逻辑，按模型规则计费。用户不必填写 Manifest；页面突出用途、输入输出、示例和删改清单，高级配置仍可手动检查。

原始草稿有明确标记，不能绕过 AI 整理直接保存为运行版本。标准 `SKILL.md`、目录和 ZIP 入口仍然严格检查格式，不自动修补不合法的文件包。

1. 标准文件包必须先通过格式校验；显式的 GPT 草稿入口只把原始内容作为待创作资料，不直接批准其为可运行 Skill。
2. 文本主模型读取完整 `SKILL.md` 和导入的文本参考资料，结合当前本站模型目录生成适配正文、运行 Manifest、使用说明和变更清单。单次适配输入最多 12 万字；超过模型配置的提示词上限会在提交模型前阻止，不会截断资料后假定完整兼容。
3. 图片、视频、音频的外部调用可映射为本站 `text_to_image`、`image_to_image`、`text_to_video`、`image_to_video` 等已注册处理器。实际模型由原有模型管理/生成引擎选择并按原规则计费，不使用独立的 AI 聊天供应商网关。
4. 模型列出被替换、被移除的能力以及剩余限制；有删减就标记为「部分适配」。核心能力无法完成时拒绝生成可导入结果，不用虚假的兼容结论代替失败。
5. 管理员可对照原始文本、适配正文和运行配置，勾选确认后才能导入。最终接口再次验证格式、Manifest、映射处理器和当前模型能力，导入后仍默认下架、对外开放关闭。

## 执行与原文隔离

适配后的执行文件为独立的 `SKILL.md`。必需专业知识应由模型合入适配正文，不再引用未适配的外部脚本或原文件。

原始文本文件和变更说明保存在版本的 `import_source` 留档列，后台「运行版本」可查看。该列不在公共模型 JSON 中输出，不进入运行提示词，也不放进公开安装包/MCP 响应。复制版本保留来源，替换整个文件包时清除旧来源关联。原文的许可声明和作者 metadata 保留在适配版头部。

只有文字资料被保留；导入器原本忽略的 Python、JS、HTML、二进制文件仍不会进入可执行包。

## 边界

- 当前不是通用代码 Agent：不会执行 `bash/python/npm/git` 或自行安装依赖。
- 当前受控 Skill 处理器未开放网页部署、视频拼接、逐帧生成和自动抽末帧等步骤。这些只能删去或明确要求用户另行完成。
- `{{previous}}` 是上一结果的文本/地址占位符，不是将上一步图片自动绑定为下一步视频参考素材的通用机制。不能将这种缺失伪装成可用的连续链式视频能力。
- 适配是一份模型生成的可审核草稿，不保证任意第三方 Skill 都能等价迁移。需要管理员确认实际交付范围；真正的生成效果还需使用选定模型验收。
- 多 Skill 包需拆分逐个 AI 适配；关闭此选项后可保留原有手动批量配置流程。
- 自动生成配置本身按现有文本模型调用计费，不会为了“试运行”另外生成付费图片或视频。

数据库新增的 `skill_version.import_source` 由 AutoMigrate 创建，需要主站前后端同步更新。MCP 继续调用已发布的同一个 Skill 版本，无需独立改包。
