# Framelyn frontend

Visitor modes: Persuade for the landing/developer/pricing pages; Operate for the studio/account/library; Read for API documentation. Scope is a complete independent English frontend using the existing backend. The user chose a simple, distinctive dark creative tool and delegated the provisional English brand choice.

## Direction contract

THESIS: Give creators a focused place to move from an idea to an owned result, with a separate, explicit path for developer integrations.

OWN-WORLD: Graphite surfaces, pale chartreuse actions, a compact frame symbol, self-hosted sans typography, thin neutral seams and imagery that supplies the color. No origin-project logos or promotional footer.

STORY: Discover a visual direction, enter the studio, choose a live model, verify the cost, generate and follow a result. Developers see the same account's key, actual endpoints and outcomes.

FIRST VIEWPORT: A restrained horizontal navigation bar; a large two-line promise on the left and overlapping photographic reference frames on the right. The workspace uses a 224 px rail, an actionable composer and an adjacent results area. Docs keep anchored wayfinding next to readable examples.

FORM: The user-pinned dark working surface takes precedence over the roll. Seed key: 641f7c75. The interface uses standard controls and gives the reference imagery a distinct frame language, without disguising the product as a physical artifact.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
