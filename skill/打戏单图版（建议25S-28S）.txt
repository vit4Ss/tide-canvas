  · 强制瞬移跳位：主角与当前阶敌人在场景里疾掠 / 腾跃 / 俯冲 / 蹬壁 / 踏空 / 相位穿插，有清晰空间跳变（贴脸 A → 高空 B → 远景 C），严禁全片钉在一个点。每次换代都把战线推向更远、更高或更开阔的新区域。
  · 强制技能招式化：主角和三阶敌人的技能都要有具体形态、轨迹、落点、反制关系与后果，不许用笼统的"能量爆发[辉光]"糊弄。每出现更强一阶敌人，主角必须解锁一个此前未用过的新动作机制，而不是只把同一招放大；若主角无明确武器，新机制优先来自步法、拳掌肘膝、摔投擒拿、发力结构与环境借力，不从已退场的生活道具里硬造能力。
  · 强制作画多样性：瞬移 / 踏空 / 近身攻防 / 远程压制 / 精准破坏 / 大招对轰交替推进，禁止连续 3 个以上同质动作。破坏是双方力量升级的可见刻度，不是无目的特效堆叠。
  · 双体/多体参考图 → 图中已有角色继续按外貌和阵营锚定；若画面已经明确给出对手，优先把现有对手设为精英或首领，再按剧情需要补充同势力低阶单位。新增敌人仍从镜头2后有因果入场，绝不改写首帧人数。
  ※ "攻击受体"与"敌人"并存：敌人负责攻防博弈，近战级 / 结构级 / 火力点级 / 空中级受体负责承接外溢力量和显示破坏规模。两者都按【武器/技能尺度 × 当前敌人强度 × 参考图场景世界观】现场设计，不能只砸背景不打敌人，也不能只打敌人而让场景毫无升级反馈。

番剧感 = 瞬移跳位 + 疯切镜头 + 作画特效层，三者同时拉满。这三条是本模版区别于写实版的灵魂，任何时候优先满足。

━━━ ★★★ 头号铁律 · 连续运动、禁停格（优先级高于一切，先读这条）━━━
病因：番剧里的"冲击帧 / hit-stop 顿帧 / 定格"只有 1-2 帧、眨眼即过；但 AI 视频模型（即梦 Seedance / Kling）没有帧级控制力，你写"定格 / 停格 / 顿帧 / 慢动作 / 升格 / 子弹时间 / 时间静止"，它会把整段画面**真的停住零点几秒**。这些指令一堆，视频就变成"打几下→停→打几下→停"的顿挫感。
铁律：① 全片画面**必须持续运动**，绝不出现整帧静止；② 冲击强调一律改用**不停画面**的手法——白闪一两帧（画面继续走）、镜头猛震一颤、命中点径向速度模糊、速度线爆开、色彩瞬间提亮；③ **升格（慢动作）分两级、放开用**（模型能做好受控慢镜，别再一刀切）：〔命中顿·微升格〕每个关键命中/爆点都可 ramp 进一个极短微升格（~0.3-0.5s）做"顿一下"、再 snap 回全速把目标炸飞——**可多次**；〔名场面·大升格〕镜头9-12核心大招那一次给全片最长最炸的升格（≤0.4s+360°环绕）。★ 两级共用**唯二铁条**：① 必须绑流动元素（碎屑/火花/水花/气浪仍在缓慢流动外扩，不是冻结）；② 时间轴 ramp in → snap back，不裸停；④ 全程**禁用**这些词：定格、停格、顿帧、hit-stop、凝滞、静滞、悬停、子弹时间、时间静止、时停。"快到看不清"靠速度线+残影表现，不靠停画面。⑤ ★ 分清"停格"与"慢拍"：本铁律禁的只是 A 类【真放慢时间/真停住】；而 B 类【低幅度慢拍（蓄力/接招/收势——画面仍在动、只是动作幅度小）】不在此列，反而是节奏感的主来源、必须有（详见【节奏魂·两种慢】）。别把"禁停格"过度执行成"全程不许慢半拍"。


━━━ ★★ 二号铁律 · 动势衔接、动作接力（治"疯切被执行成疯乱/发飘/接不上"，与头号铁律并列）━━━
病因：番剧疯切之所以丝滑，是人肉原画师让"动势（运动方向 + 速度矢量）跨切延续"——上一刀的劲儿，下一刀接着走，眼睛被顺滑地带过切点。但 AI 视频模型（即梦 Seedance / Kling）没帧级控制、做不出干净剪辑，你只堆"每 0.2s 硬切到新方位"却不交代动作怎么接，它就把瞬移执行成肢体扭曲（morphing）、位置乱飘、动作没做完就跳走——"疯切"变"疯乱"，一顿一顿。刀数够、却不丝滑。
铁律：① 弧线跟随：每个动作走完整弧线（起势→发力→跟随 follow-through），别只给发力那一帧就切走，留一点收势让动作"落地"，别处处半截。② 切在动作中段（cut on action）：切点落在挥砍/突进正发力的中途，用动作本身盖住剪辑；严禁在静止帧、姿势停顿处切。③ 方向接力（match-cut）：硬切/瞬移前后运动方向一致——上一镜向右上挥出，下一镜就从右上续着走；残影链与速度线一律指向落点，让瞬移读成"顺着同一股劲唰地掠到位"，而非"凭空 glitch 闪现"（省略的是移动过程，不是移动方向）。④ 收势变起势：上一招的收尾直接长成下一招的起手，动作像一条不断的线穿过所有切点；残影/速度线是承载这条线的胶水，不只是遮盖切换的遮羞布。
※ 与头号铁律的分工：头号管"画面别停"，二号管"动作别断"——两条合起来才是"丝滑高速"。★ 疯切密度不用砍（照样快、照样碎、节点照样 ≥50），要补的只是"每一刀都接得上"。


━━━ ★★ 三号铁律 · 空间单向推进、禁回原点（治 img2video"首帧引力/loopback"）━━━
病因：img2video 对参考图首帧忠诚度极高，会把它当"家"——人物动着动着被拽回起始位置与构图，甚至片尾又绕回开头（模型天生想让片子能 loop）。若正文再出现"归位/回到坐台/落回原处"字样、或反复用与首帧雷同的正面居中构图，等于亲手把它送回起点。
铁律：① 空间单向推进：全片位置沿 A→B→C→D 累积净位移、越打越远离起点（起手区 → 中段扫过场景 → 终点落在离原点最远的新区域，如远端/高处/另一侧结构前）；跳位三连是"往前跳"不是"绕圈跳"，绝不回到已经离开的位置。② 末帧 ≠ 首帧：靠"最后一击就发生在离原点最远的新区域"自然达成——人物打到哪、爆闪就黑在哪，与参考图首帧的机位/区域自然拉开。★ 不靠在爆闪后另写一句"末帧定格在…背身立于…"（那既违反收尾爆闪即止、又把收尾拖散）；收尾就是前面动作推到最远处、爆闪瞬黑为止，绝不补末帧落定描写。③ 禁字：正文不写"归位 / 回到原处 / 落回原座 / 回到起点"。
※ 与首帧锚定的分工：镜头1锚住首帧起手（该守），镜头2之后必须持续推进离场（别被拽回）——锚开头、不锚全程。★ 三条铁律合起来 = 时间不停（头号）/ 动作不断（二号）/ 空间不回（三号）。


━━━ 引擎一 · 空间瞬移跳位 + 怼脸弹射（"上一秒在远处、下一秒怼到镜头前"的真相）━━━
番剧里角色"瞬移"不是真的表演位移，而是**用镜头把移动过程省略掉**制造的错觉。四种手法混用：
  ① 硬切跳位：一个招式命中/挥空的瞬间硬切 → 下一帧主体已经在完全不同的【景别 + 方位 + 高度】（贴脸特写 → 硬切 → 高空全景 → 硬切 → 贴地近景），中间的移动完全不给看。这是番剧瞬移的主力手法。★ 但要丝滑（治 AI morphing）：切前的运动方向与切后的落点方位必须一致、残影与速度线指向落点——省略的是移动过程，不是移动方向；让它读成"顺着同一股劲唰地掠到位"，而非"凭空 glitch 闪现"（详见二号铁律）。
  ② 残影留位：主体在 A 位置留下一道/多道残影（afterimage），实体已经出现在 B 位置——"人还没反应过来，他已经到了"。
  ③ 速度线掩护：一道横向速度线/集中线扫过画面，主体"擦"着线从画面一端瞬闪到另一端，用线条盖住移动细节。
  ④ 交错错身：两人高速擦身而过、错身继续冲出（画面绝不停顿，气流与残影持续拖动）→ 其中一人身形在冲出中一颤（被命中的反馈在运动里爆发）。番剧经典的一拍，但靠速度线+残影拖尾表现"快到看不清"，不是靠定格停住。
  ⑤ 怼脸弹射（★ 动漫回合交换的招牌手法，最出"魂"）：轮到谁反击，谁就从极远"唰"地弹到画面最前方——拳头 / 刀尖 / 脸怼到镜头前，超近景冲脸，带径向速度模糊 + 速度线朝镜头收束。那股"他一瞬间就到你面前了"的压迫感，就是你要的动漫感。用它做每个回合的攻守交换： 但整个片段只能在最燃的地方使用一次。
  ★ 硬指标——【跳位三连】：全片至少嵌 3 组"位置跳变链"，每组内主体的【景别 / 方位 / 高度】至少两项发生跳变。范例：〔贴脸特写·画面右·低位〕→硬切→〔全景·画面左·高空〕→硬切→〔中景·正面·贴地〕。每 2-3 秒必须发生一次这种跳位，绝不让主体在同一景别方位停超过 2 秒。★ 但整片这些跳位要累积成净位移、越跳越远离起点（见三号铁律·空间单向推进），是"往前跳"不是"绕一圈又回到原地"。
  ★ 但瞬移是"招式之间的连接"，不是主体——跳到新位置就要立刻打出一个不同的招（见引擎三节点密度），别为跳而跳、空跳不打。

━━━ 引擎二 · 疯切镜头（crazy cutting · 作画式分镜）━━━
番剧分镜切得极碎、角度极狠，与写实版的"手持贴身跟拍"完全不同：
  · 平均镜头长度（ASL）极短：0.2-0.5 秒一刀，每个攻防节点几乎都是一个独立机位。
  · 大量荷兰角（dutch angle 倾斜构图）、极端广角透视（近大远小夸张）、鱼眼冲击、贴脸大特写与全景远景的**暴力反差跳切**。
  · ★ 冲击强调（★ 画面绝不停住，见头号铁律）：命中冲击一律用不停画面的手法表现——白闪一两帧（过曝闪光，画面继续走）+ 镜头猛震一颤 + 命中点径向速度模糊 + 速度线爆开 + 色彩瞬间提亮。观众照样觉得"这一下很重"，但画面始终在动。严禁写"定格 / 停格 / 顿帧"。
  · 甩镜衔接（whip pan）：镜头猛甩糊成流光，接下一个机位，掩盖切换、强化速度。
  · 抽象背景切换：爆发/蓄力瞬间背景瞬间抽象化成纯色 + 放射集中线 + 速度线（番剧特有的"打斗抽象背景"），把注意力全压在主体动作上。
  ★ 硬指标：全片 ≥25 个不同机位/切换，平均镜头 ≤0.5s；镜头1首帧锚定段可稍长（锁参考图），镜头2之后进入疯切。

━━━ 引擎三 · 作画特效层（anime sakuga VFX · 替换写实物理反馈）━━━
番剧特效是"手绘作画感"，不是写实粒子。每一个动作节点都必须挂 ≥1 层作画特效，五类混用：
  · 线条特效：放射状集中线（蓄力/爆发）、横向速度线（疾掠/挥砍）、动作拖影线、冲击时的爆闪线。
  · 冲击强调特效（画面不停）：命中瞬间白闪一两帧 / 色彩瞬间提亮 / 命中点径向速度模糊 / 镜头猛震一颤（禁"定格 / 顿帧 / 停格"——那会让 AI 视频停住画面）。
  · 单色调冲击（★ 你要的"突然切黑白 / 切红色"）：重击/决胜/情绪爆点瞬间，整屏 0.1-0.2s 染成高对比黑白 或 单一色调（红=杀气危机 / 蓝青=冷冽杀招 / 金橙=大招充能 / 紫品红=能量过载）再切回——画面动作全程不停，只是颜色被瞬间抽换一闪，配集中线内收/爆开 + 漫画线条背景。详见弹药库【单色调冲击 + 线条爆发库】。
  · 气场斗气：环绕身体的能量气焰/斗气、地面被气压压出的环形气浪、蓄力时气场暴涨掀飞碎石与发丝。
  · 残影分身：多重残像拖尾、动作抹除帧（smear frame 夸张形变）、瞬移留下的半透明残影链。
  · 能量与粒子：像液体/火焰般流动的能量、光尘逆光海量浮游、能量碎屑如萤火、刃光过留下的青白光轨残影、能量迸发的镜头光晕。
  ※ 挂载口诀：动作动词 → 紧跟 [作画反馈]（受体如何崩裂/断裂/被击飞）→ 再叠一层作画特效（速度线/白闪震镜/气场/残影），三段式让每个节点都"有肉有光有线"。

★★ 节奏魂（本模版第一性原理 · 先读这条）：动漫打斗的燃来自「幅度落差」——一慢一砰、蓄够了才爆，不是「全程匀速最快」。★ 真理：【全程快 = 没有快】——匀速密不透风，大脑会把这密度当成新的匀速常态、重音被抹平，再多特效也砸不出打击感。所以打斗 =「高速连打」为底色 ×「回合单元」为组织 ×「幅度落差」为打击感来源，三者叠加。
  · 底色仍快：全片节点 ≥50、疯切 ≤0.5s 一刀，不砍——但"快"必须靠"慢拍"衬出来才成立。
  ▼ ★★ 两种"慢"必须分清（治"想要节奏"被误做成"放慢时间 → AI 卡死"）：
    · A 类 · 真放慢时间（升格 slow-motion）：★ 受控放开·模型能做好——命中顿微升格（每个关键爆点 ~0.3-0.5s、可多次）+ 名场面大升格（镜头9-12那 1 次最炸），两级都必须绑流动元素（碎屑/火花/水花仍流）+ ramp in→snap back（见头号铁律 ③）。★ 仍禁的只是【裸写冻结词/整帧真停死】（定格/顿帧/时间静止/子弹时间——照字面执行会卡死）。
    · B 类 · 低幅度慢拍（蓄力/接招/对峙/收势）：画面照常动（气场涨、发丝布料飘、肌肉绷、腕上气纹内收、呼吸起伏），但【动作幅度极小、发力集中】——读起来"慢/稳/蓄势"，实则一帧没停。★ 这才是节奏感的主来源，对 AI 视频完全安全，必须有。
    ※ 范例（灵笼）："白月魁单手稳稳扣住劈来的重锤"= B 类慢拍（小幅度接招），紧接"一脚踹飞数十米"= 大幅度爆发；时间没放慢、画面没停，你却明确感到"一慢一砰"。你要的节奏 = 幅度节奏（小幅度↔大幅度）+ 剪辑节奏（长镜对峙↔快切连打），不是速度节奏——别用 A 类做，用 B 类。
  ▼ 单个回合的骨架（慢拍 → 爆发 → 重音 → 击飞 → 收势，画面全程在动、零 A 类停格）：
    ① 慢拍装弹（B 类·小幅度，★★ 每个回合都要有、绝不只在开场——这是最易翻车处）：分两型——【进攻蓄力型】攻击者出手前自己先"慢一下"沉住蓄力（沉刀/收拳/气纹缠绕护手/重心下沉/刀往后缓拉），★ 这就是"攻击时慢一下"的招牌拍、每个进攻爆发前都复现一次；【防守接招型】沉腕稳稳格住/接住来招纹丝不退。画面在动（发丝布料被余力掀起、雨珠尘埃悬浮），但动作幅度压到最小、发力集中，读作"慢半拍"。★ 落差就在这攒：慢拍越沉，下一下越炸。（≤0.5s）★★ 写法铁律：蓄力慢拍要【独立成一拍、给它视觉留白】，别把它溶进后面的连招 run-on 串里一闪而过——溶进去就读不出"慢一下"、节奏塌回匀速（★ 这正是"慢都堆在开场、攻击时没慢一下"的病根）。〔也可用怼脸弹射做高幅度入场，但入场后、命中前仍要单独塞这半拍蓄力慢拍〕
    ② 高速攻防肉：一串 0.2s 的招式链/攻防往复（连斩、连点、瞬移绕后、残影连击），幅度骤然放大，回合主体，密不透风。
    ③ 碰撞爆点（命中重音）：回合高潮——命中那一格，spacing 骤然拉大 + 单色闪（黑白/属性色）+ 样式化线条炸开 + 冲击形变 + 白闪一两帧 + 镜头猛震 + 径向速度模糊 + 作画反馈 [...]。★ 重音靠"突变"（幅度+特效同时炸）砸出，是【逗号不是句号】：白闪一两帧、画面立刻继续，绝不停死。
    ④ 击飞：被命中者【快速拖出画面/结实砸地撞墙】（灵笼力学流，非慢镜漂移；想走日式炫技慢镜漂移则叠一个命中顿微升格/名场面大升格）——见弹药库【击飞两流派】。
    ⑤ 收势喘息（B 类慢拍）：出招方披风头发武器滞后飘动、惯性带身形缓转落定、灵笼式长呼一口气发梢未歇——给下一次慢拍留"呼吸谷底"。★ 这不是 A 类停格（画面仍在动：惯性余韵、发梢未歇），是节奏休止符；攻守交换就从这谷底、对方怼脸弹射反入场、无缝切进下一回合。〔末个回合例外：不留收势，直接末击+全屏爆闪收黑，见镜头15〕
  ★ 关键校准（别再做错）：① 回合的"顿/重音"靠爆点那格的【幅度+特效突变】砸出、不靠把时间放慢——这条不变；② 但"慢拍（①）"与"收势喘息（⑤）"是 B 类低幅度慢拍、画面一直在动、【每回合必有】，不是"卡带"，是给爆发装弹的落差。★ 旧版"底色一刻不慢/严禁回合间隙喘息"是矫枉过正，现更正：禁的是 A 类真停/真放慢，不禁 B 类慢拍。
  ※ 15s 排布：约 4-5 个回合，每回合走"慢拍→爆发→重音→击飞→收势"，主角与当前阶敌人轮流夺势；敌人按第一阶→第二阶→第三阶逐步接管更高强度的回合。下面四阶段是这些回合的宏观分布。

▼ [镜头1-4 激战爆发] —— 任务：前3个镜头内让观众心跳加速
  · ★ 首帧锚定（最高优先）：给了参考图 = 参考图就是视频第 1 帧！镜头1从图中主体的当前姿态、当前景别直接启动，第一个动作是主体自身的起手（眼神骤变 / 拔刀 / 瞬身蓄力 / 迎击）。镜头1别急着疯切，先让主体动起来。
  · 1s 之后引擎全开：第一阶敌人从画面深处/边缘以明确路径进入，第一次兵刃/技能接触 + 第一个作画反馈 [...] + 第一次瞬移跳位 + 第一次白闪震镜冲击（画面不停）。
  · 本阶段只做【局部级】破坏：桌椅、门窗、地砖、小型掩体或贴近主角的局部结构受力；敌人能力单一、主角仍占绝对主动，为后续升级留空间。
  · 忌：慢热铺垫、静态站桩对视（哪怕 0.5 秒；番剧的蓄力预备也带气场/发丝微动，绝不整帧静止）。

▼ [镜头5-8 节奏博弈] —— 任务：2-3 个回合的攻守交换（每回合：慢拍蓄力/接招装弹 → 高速攻防 → 碰撞爆点·幅度+特效突变 → 击飞收势 → 怼脸弹射交换进下一回合）
  · 第二阶精英/重装敌人必须接管战局，至少正面挡住、化解或反制主角一次关键招；主角被迫改变方位、武器用法或技能机制后再夺回主动。攻防有因果链：A 瞬身出招 → B 残影闪避/踏空化解 → B 怼脸弹射反入场反制。禁止双方互殴无逻辑。
  · 必含：≥2 次作画反馈 [...]、≥1 组跳位三连、≥1 次怼脸弹射攻守交换（对方瞬间怼到镜头前反击）、每个回合的碰撞爆点都挂单色闪+线条炸开。
  · 破坏升级为【房间/结构级】：战线从首帧所在小区域推入走廊、楼层、庭院或相邻结构；立柱、墙体、平台、桥面等承接双方冲击，镜头视野与交战半径明显大于镜头1-4。
  · 推荐运镜：荷兰角疾切、甩镜衔接攻防、贴脸特写与全景暴力跳切、残影拖尾横移。

▼ [镜头9-12 巅峰对垒] —— 任务：全片最炸的 4 个镜头，技能/大招/名场面全开
  · 第三阶首领/巨型强敌以全片最强压迫感现身，入场动作本身必须改变战场：压塌大型结构、撕开地表、撞穿建筑外壁、遮蔽天空或展开覆盖大片区域的技能场。它必须连续化解主角至少一组常规连招，并用独有能力迫使主角第一次完整释放核心大招。
  · 必含：全片最长最炸的那 1 次名场面大升格（≤0.4s，且升格中碎屑/气浪/能量仍在流动，不是冻结）展现核心招式名场面 + 高速环绕运镜 + 最大规模的能量/作画特效爆发 + 背景抽象化成纯色放射线 + 大招充能瞬间金/紫单色染屏。★ 这是全片最大那次升格；其余关键命中另用更短的命中顿微升格（~0.3s、绑流动元素）做"顿一下"，见头号铁律 ③。
  · 蓄力→爆发→释放三拍：蓄力时集中线内收+气场暴涨+镜头逼近，爆发瞬间白闪一两帧+镜头震动+背景炸成放射线（画面持续走），释放时能量束/斩击贯穿首领防御并继续作用于其身后的大型结构。
  · 破坏升级为【建筑群/地形级】：战线必须冲出或撕开原始封闭场景，进入屋顶、广场、山谷、城市上空、舰体外部等更大空间；破坏具有方向性和因果链，由首领能力或双方碰撞引发，不是随机全景爆炸。

▼ [镜头13-14 巅峰高潮] —— 任务：全片最密集的攻防在这里爆发
  · 这 2 个镜头只保留主角与第三阶最强敌，是激战顶点；塞入全片最连贯最快的招式链（连续瞬移 + 连点刺 + 残影缠斗 + 技能对轰），动作密度与疯切频率全片最高，几乎每 0.2s 一切。决胜那记重击瞬间来一次黑白闪或红染（全片染色的高潮落点）。
  · 破坏升级为【地标/天象级终值】：决胜碰撞必须影响全片最大的可见范围，如贯穿地标、切开云层、掀起跨街区冲击环、令巨型舰体/山体外壳/能量穹顶发生连锁变化；尺度必须来自双方最终招式，不准突然无因放大。
  · 收尾前的镜头13-14绝不留给磨蹭或慢镜，要打得最凶。

▼ [镜头15 终极收势] —— 任务：最后一击命中 + 全屏爆闪，视频到此结束
  · 就一下：主角最后一击命中第三阶最强敌的那一格 + 全片最大范围的场景反馈 + 全屏爆闪（白闪 / 属性色闪，按大招定色）+ 闪光中直接收黑或收白，视频结束。仅占 1 个镜头，越干脆越好。
  · ★ 爆闪 = 命中瞬间同步发生，闪光本身在动、直接盖掉画面收尾——不是"打完→画面停住→再爆闪"（那是定格，违反头号铁律）。爆闪替代了"持续运动源"：画面到闪光就结束了，根本没有末拍留白，也就没有"强行停止"感。
  · 变体（想避免每条都白闪时二选一）：① 属性色爆闪收尾（红/金/黑白，贴大招属性）② 动量出画——末招甩出画外、速度线漫过镜头瞬间收黑。
  · 忌：镜头缓慢拉远/环绕收尾、升格慢收、收尾拖到 2-3 个镜头、打完画面停住再结束。

★★ 双递增曲线（敌人升级 × 场景升级 · 贯穿四阶段，禁止前重后轻）：
  · 敌人压力曲线 E1→E2→E3：基础兵种只逼出身法与普通招；精英必须完成一次有效防守和一次反制，逼出进阶招；首领必须压制常规招、改变战场并逼出核心大招。后登场者在【体型/速度/防御/武器/技能范围/战术判断】中至少两项高于前一阶，不能只是换皮或增加数量。
  · 场景尺度曲线 S1→S2→S3→S4：局部物件级 → 房间/结构级 → 建筑群/地形级 → 地标/天象级。每一级都由具体招式命中、敌人入场或攻防碰撞触发；新一级覆盖范围显著扩大，但保留上一级造成的痕迹，让观众读到累积升级。
  · 破坏量曲线小→中→大→最大：镜头1-4只给小反馈，镜头5-8出现结构性破坏，镜头9-12首次大范围崩解，镜头13-15才释放全片唯一最大规模。严禁开场就炸完整栋建筑，导致后面无处升级。
  · 空间曲线与三号铁律绑定：战线沿 A→B→C→D 单向扩大，主角与敌人越打越远离首帧起点；场景升级靠穿门、破墙、跃层、冲上高空或冲出封闭空间自然完成，禁止无因瞬切到陌生世界。
  · 技能曲线“机制升级”优先于“光效变大”：每一阶敌人带来新问题，主角用新机制破解；最终大招应综合前面建立的身法、武器和属性，而非凭空出现从未铺垫的能力。

节奏铁则（战斗片的命脉 · 最高优先）：这是高速番剧战斗片，不是慢镜头 MV。硬指标——全片 15s 有效动作节点（一次攻 / 挡 / 闪 / 瞬移跳位 / 反制 / 蓄力 / 技能 / 破坏 / 能量释放各算一个独立节点）：★ 绝不低于 50 个（番剧爆裂档，比写实版更密，每 ≤0.3 秒一个），任何情况都是硬下限。 ※ 但"密度高"≠"匀速最快"：蓄力/接招/收势等 B 类低幅度慢拍照常计入节点（它们本就是节点），靠慢拍↔爆发的幅度落差出打击感；别把"节点 ≥50"误读成"全程 0.2s 匀速、不许慢半拍"（详见【节奏魂·两种慢】）。
※ 有效动作严格数法（防"看着满、实际空"）：数节点时砍掉三种水分——① 环境反应 / 作画反馈不算（那是 [] 里的特效，不是动作）；② 同一类动作换词重复只算 1 个（俯冲→撕空→急转→再俯冲 = 1 种飞行位移）；③ 纯状态（发光 / 蓄能 / 悬停）不算。凑够 50 靠"有区别、推进性的招式"——每 1.5-2 秒尽量换一个不同的招（斩 / 突刺 / 掌击 / 踢技 / 能量弹 / 瞬身撞 / 缠绞…），而非同一个动作反复飞 / 反复砸。瞬移只是招式之间的连接。
加密到 50 的手法：① 连招拆分（"连斩三刀"拆成 3 个独立节点）；② 攻防急速往复（攻→挡→反→闪 一秒内塞完）；③ 加入拧腰 / 点角 / 踏空 / 借力等过渡微动作；④ 疯切本身制造节点（每次硬切跳位到新方位打新招 = 新节点）；⑤ 单图对敌则用"杂兵清场→精英反制→首领压制→主角破局"拆出不同机制节点，同时递增空间与破坏规模。生成时用编号 ①②③… 逐个标注、方便自查数量——但⚠ 最终交付的提示词正文必须清除全部节点编号，只保留 [镜头1]、[镜头2]…镜头编号与 [作画/物理反馈]，是一段纯净连续文本。单一动作不得占用超过 1.2 秒（番剧比写实更碎）。

⚠ 最易踩的坑 · "快 ≠ 减字减特效"：加密动作时严禁靠删描写来提速！每个动作节点都必须就地紧跟 [...] 作画反馈 或 特效层描写——动作越密、特效越满、字数越多，这三者同向增长。要砍的只有"开场之外的静态环境铺陈"（氛围铺陈仅限镜头1）；动作自带的速度线、气场、光影、残影、粒子描写一律保留且要饱满。若成品字数偏少，一定是特效没写够，去补。

写法用【招式链】：短句、顿号快速串联攻防往复（攻→挡→反→闪→瞬移→再攻），且每个招式后就地挂 1 层作画反馈 / 特效，见弹药库。★ 招式链按【回合单元】分组：每 2-3 秒一个回合（怼脸入场 → 0.2s 高速攻防 → 碰撞爆点演出炸满 → 怼脸弹射交换），回合之间用怼脸弹射衔接，别写成一条没有段落、没有重音的匀速连打。
※ 上方四阶段是宏观节奏骨架，实际正文必须依次使用镜头编号标注（如 [镜头1]、[镜头2]…），严禁再输出任何秒数时间戳；每个镜头保持原有高密度动作与快切节奏。

R1 · 动作-反馈闭环（★ 不只攻击——**任何动作都要有反馈，且反馈必带回馈特效**）
  ★ 每一次攻击性招式（斩击 / 突刺 / 掌击 / 能量弹 / 大招）都必须打在当前阶敌人或明确受体上、并给出与这一击分量匹配的具体后果，形成"攻击 → 命中/化解 → 敌人或受体反应 → 回馈特效"的闭环。敌人不能只充当被命中的靶子：每一阶至少有一次主动进攻，精英与首领必须出现有效防守/闪避/反制。严禁"对着前方 / 墙 / 地面放招，再贴一个笼统的 [崩解 + 火花]"——那是朝空气放烟花。
  ★ 移动/位移也要反馈（★ 别只给攻击反馈）：高速移动 → 地面因快速产生回馈 [扬尘/裂地/水花溅开/环形气浪] + 一个速度特写（腿/脚/身体局部+速度线）卖"快"；踏地、蹬壁、落地、疾掠每一下都留回馈痕。
  ★★ 反馈必带回馈特效（缺一不可）：任何反馈都不许光写"目标断了/地面裂了"却不挂特效——反馈本身就要带火花/尘爆/碎块/速度线/白闪/单色闪。挂载三段一体：动作动词 → 紧跟 [作画反馈] → 反馈上再叠回馈特效。
  · 有明确落点：不是泛化的"前方 / 墙面"，而是当前阶敌人的具体防守部位/武器/技能节点，或按近战级 / 结构级 / 火力点级 / 空中级四维现造的具体受体；敌人与场景反馈同时服务于强度和规模升级。
  · 后果匹配分量且每次不同：连斩 → 目标被斩成数段/整齐断裂；掌击/撞击 → 目标被击飞老远撞穿结构（番剧允许夸张击飞）；能量束大招 → 目标被洞穿/整体崩塌坍缩/连锁殉爆。攻击越重、反馈越大，别复读"[崩解、火花]"。
  · ★ 番剧强化：命中瞬间标配【命中一拍四段】= 接触（震镜+径向模糊+白闪）→ 顿一下（命中顿微升格 ~0.3-0.5s、绑流动元素）→ 击飞（snap 回速 spacing 骤拉）→ 目标反馈+回馈特效。★ 命中顿用【微升格】做（绑流动元素+ramp，见头号铁律 ③）而非裸冻结；仍禁裸写"定格/顿帧/时间静止"。画面始终有流动元素在动。

R2 · 番剧级镜头调度（疯切 · 非纪实跟拍）
  必须包含疯切硬跳、荷兰角、贴脸↔全景暴力反差切、甩镜衔接、白闪震镜冲击、抽象背景切换、高速环绕等作画式运镜，按四阶段各自的推荐运镜搭配。具体见【弹药库·疯切运镜库】。区别于写实版的手持微晃——番剧要"刀刀狠、切切跳"。★ 升格放开用：命中顿微升格按需多次 + 名场面大升格 1 次（均绑流动元素+ramp）；仍禁子弹时间/定格/顿帧这类【裸停格】运镜。

R3 · 叙事连续性（瞬移不等于断裂）
  疯切与瞬移必须靠角色动作逻辑串起来（残影留位 → 实体到位、借力回旋 → 硬切新方位、踏空蹬墙 → 跳位）。硬切跳位前后要有动作因果，不是随机乱跳。速度线/残影/错身冲出是掩盖切换、维持连续感的胶水（这些手法本身都在运动，不停画面）。

R4 · 动漫物理自洽（★ 本版专属：放开现实物理，守招式内部逻辑）
  番剧允许一切超现实动漫惯例：空中多段跳、踏空静立、贴墙奔跑、瞬身闪现、多重残影分身、一击把目标打飞老远撞穿数道结构、蓄力爆气掀飞环境。（⚠ 但"时间静止/时停"这类惯例本版不用——AI 视频会把它执行成画面卡死，与头号铁律冲突。）但**招式的内部逻辑仍要自洽**——识别武器/技能真实属性再匹配打击感：
  · 刃 / 刀类 → 斩、刺、旋斩、连斩、居合、飞斩气刃；打击感为切割穿透、整齐断裂、刃光残轨；断面可夸张但仍是"被斩断"，别写成钝器砸烂。
  · 钝 / 拳脚 / 冲击类 → 砸击、掌击、崩拳、踢技、撞飞；打击感为凹陷形变、冲击波扩散、目标被击退击飞（番剧可夸张飞很远）。
  · 能量 / 魔法 → 灼烧、爆炸、电弧、湮灭、光束贯穿、法阵崩解。
  · 体术 / 身法 → 关节技、摔投、精确打击部位 + 瞬身残影连击，打击感为闷响与身体弯折。
  · ★ 敌人/受体尺度耦合（承 R1）：敌人的体型、防御方式和受体形态都要匹配招式打击范围。近战刃/拳脚 → 同尺度杂兵、重装精英或可斩可砸的近战级/结构级受体；远程能量/魔法/飞斩 → 才可对抗空中首领、远程阵列、高空目标。敌人越强，主角招式的作用范围与场景反馈才能逐级放大；别让巨剑够不着无人机，也别让普通轻击无铺垫摧毁整片地标。
  ⚠ 唯一保留的现实约束：招式类型与武器匹配（刃斩不写成锤砸）；除此之外物理尺度全面放开，怎么炫怎么来。

R5 · 违禁词安全替换（自动 100% 应用，全程扫描）
  严禁任何暴力 / 血腥 / 死亡的直接描述，必须替换为安全中性词，且视觉冲击不变：
  · 鲜血 → 暗红色痕迹 / 能量残留辉光　· 伤口 → 破损 / 裂痕 / 印记
  · 死亡 / 尸体 → 静止 / 沉睡 / 失去意识　· 杀戮 → 制服 / 阻止 / 精准击倒
  · 暴力 / 殴打 → 冲撞 / 强烈撞击　· 恐怖 → 紧张 / 震撼

R6 · 番剧画风基准锁定
  若用户提供参考图，深度分析其番剧画风并确立为"核心风格"，战术报告与 15s 提示词共用同一条风格描述，跨模块零漂移；无参考图则默认锁【现代作画流 ufotable/MAPPA 味】，绝不允许风格漂移。风格描述写法见【弹药库·番剧画风锁定示例】。

R7 · 大神编剧模式
  根据角色反推信息，创作一个有张力、逻辑自洽的短故事，故事长度 800-1500 字，必须与角色武器 / 技能 / 性格 100% 匹配，严格遵守 R4 与 R5，写出番剧"名场面"的高燃感。参考图负责锚定主角与开场，故事必须另外设计与世界观一致的敌方势力和三阶强度升级：
  · 单图主角 → 默认写成"遭遇第一阶敌群→精英截杀/拦截→首领改变战场→主角突破上限决胜"，中段穿插至少 4-6 个高燃攻防名场面；不再用纯砸环境替代打斗。
  · 双体 / 多体 → 优先沿用图中人物关系，已有对手可直接承担精英或首领位，再补同势力低阶单位；新增敌人不得改变图中角色身份。
  · 故事里的敌人强度、主角技能解锁、战场空间和破坏规模必须同步递增，结尾的情感升华建立在主角面对最强压力后的选择上，而不是脱离战斗另起一段。

▼ 单色调冲击 + 线条爆发库（★ 番剧最带感的样式化特效 · 画面继续动、只是瞬间套一层滤镜，不违反禁停格）
  · 黑白闪：重击/决胜/情绪爆点瞬间，整屏 0.1-0.2s 去色成高对比黑白后立刻切回彩色（动作不停，只是颜色被抽掉一闪）。留给全片最重的那几击。
  · 单色染屏（全屏色滤镜闪一下）：整屏被单一色调瞬间笼罩再褪去，按情绪/招式属性选色——红=杀气·危机·暴怒 / 蓝青=冷冽杀招·寒属性 / 金橙=大招充能爆发 / 紫品红=能量过载·异能觉醒。别乱染，色要贴当下情绪。
  · 集中线：蓄力时从四周向中心内收收束、爆发时从中心向外炸开，把视线钉在主体或命中点上。
  · 速度线：横向/斜向流动线，随动作方向铺，表现高速疾掠、瞬移、连斩。
  · 漫画线条背景：爆发/大招瞬间背景整个抽象化成纯手绘线条 / 网点 / 单色放射，剥离写实环境、只留动作张力（番剧"名场面"背景）。
  · 描边剪影：逆光/爆发瞬间角色被粗黑轮廓线描边、成高对比剪影一闪。
  ★ 频率（放开高频 · 这才是动漫魂）：黑白闪 + 单色染屏要"好多次"——每个回合的碰撞爆点、每次技能发动、每次大招 / 兵刃触碰都可以来一下，全片十几次不嫌多（鬼灭 / 咒术几乎每记重要斩击、每次技能发动都染色）。关键在每次都**极短**（≤0.15s）、**闪完即回**、**融在运动里**（画面照样动、照样快），而不是长时间停在单色上——这样既满是动漫味、又不会"闪瞎眼"。集中线 / 速度线 / 漫画线条背景更可以铺满蓄力与爆发处。

▼ 动势衔接词库（★ 二号铁律落地 · 治"疯切→疯乱/发飘/接不上"，写正文时用这些词把切点缝起来）

  · 方向延续（切前切后同向 · match-cut）：顺同一弧线续挥、残影链指向落点、速度线顺移动方向铺满、自上一击落点直接续出、动势不折、切点落在挥砍/突进中途
  · 弧线跟随（给动作留收势，别半截）：完整挥出带 follow-through、收势自然坠落、惯性带动身形续转、末端拖尾顺势甩出

▼ 打击感 · 命中一拍四段（★★ 这是"快慢节奏"的核心 = 攻击命中被攻击者那一刻的感觉；每个关键碰撞点必须齐备，画面全程有流动元素、绝不裸停）
  ⓪ 命中前·装弹：半拍 B 类蓄力慢拍（攻击者出手前自己"慢一下"，★ 独立成拍、别埋进连招串一闪而过）——落差 > 速度，丢了"砰"不成立。
  ① 接触·砸入：命中瞬间镜头猛震一颤 + 命中点径向速度模糊 + 白闪一两帧（画面继续走），让冲击"砸"进画面。
  ② 顿一下·命中顿微升格（★ 命中的重音、你要的"慢一下"就在这）：ramp 进极短微升格（~0.3-0.5s），被击者身体沿受力方向猛压缩/形变（smear）、攻击者刀势跟随——★ 碎屑/火花/水花/断口仍在缓慢流动外扩（非冻结）；可多次（每个关键命中都能来）。
  ③ 击飞·snap 回速：snap back 全速，spacing 骤然拉大、被击者瞬间被打飞 / 快速拖出画面撞结构（力学真实流）。
  ④ 目标反馈 + 回馈特效（★ 缺一不可）：紧跟作画反馈 [...]（按材质，斩断/击飞/洞穿/崩塌）+ 单色闪/线条炸开/碎屑迸飞——★ 反馈本身必带回馈特效，不许光写"目标断了"却不给火花/尘爆/碎块。
  ※ 名场面大升格全片 1 次给镜头9-12大招（最长最炸）；命中顿微升格另计、按需多次。字面冻结词（定格/顿帧/时间静止/子弹时间）仍全禁——那是裸停会卡死，微升格是绑流动元素的受控减速，两回事。

▼ 幅度节奏 · 慢拍库（★ B 类低幅度慢拍取词，治"匀速快切没打击感"；画面全程在动，非 A 类停格）
  · 接招慢拍：沉肩坐马稳稳扣住来招、单手接住重锤、以刃格住劈斩纹丝不退、掌心贴住拳锋卸力——幅度极小、发力集中，发丝布料被余力掀起（画面在动）
  · 蓄力慢拍：气场暴涨+集中线内收、腕上/刃上气纹一圈圈缠绕收束、肌肉青筋绷起、重心下沉压步、刀往后缓拉蓄势——只攒不放，发梢与尘埃被气压托起
  · 对峙慢拍：低角对望锁定、呼吸起伏、气焰无声翻涌、雨滴/尘埃在气场里被点亮悬浮飘移（环境在动、人幅度极小）
  · 收势慢拍：披风头发武器命中后滞后飘动、惯性带身形缓转落定、灵笼式长呼一口气发梢未歇——给下一次爆发留呼吸谷底
  ★ 用法：★★ 慢拍不是开场一次性的！【每个进攻爆发之前】都要单独垫一个蓄力慢拍（攻击者自己慢一下）、收尾再用 1 个收势慢拍喘息；别把"慢的预算"全花在镜头1开场、后面全速冲到底（那正是"慢都在前面、攻击时没慢一下"的病根）。慢拍越沉，紧接的爆发幅度拉越大，落差 = 打击感。慢拍照常计入节点，不降密度。

▼ 特写标点库（★ insert cut 是节奏的标点符号、不是装饰；每种有专职；对 AI 视频安全——每个特写 = 一个新镜头，不涉停格）
  · 握拳/攥刀特写 → 预告发力（"上膛信号"），插在出招前
  · 脚掌蹬地/碾地特写 → 交代"力从哪来" + 强调重量，插在突进/踹击前（配尘土/地裂）
  · ★ 移动速度特写 → 卖"快"（区别于蹬地=力源）：人物高速移动途中，切一个腿部/脚步/身体局部/衣摆翻飞的大特写 + 满屏速度线 + 地面回馈（掠过处扬尘/水花/残影），让观众"读到"这一下有多快，插在位移过程中
  · 刀出鞘/举械/寒光特写 → 制造期待，插在交锋前
  · 眼神/瞳孔锁定特写 → 延迟满足，插在命中前一瞬（"下一帧要出大事"）
  · 命中局部特写（拳砸/刃入）→ 节奏重音·落点，命中瞬间切对侧角度
  · 被击者反应/踉跄特写 → 因果闭环之"果"，命中后一拍稍长，用反应确认这一击的分量
  ★ 一个完整重音单元 = 蓄力特写（因）→ 命中（连接）→ 反应特写（果）；别只画命中不给反应，否则冲击没有落点。

▼ 击飞两流派（★ "被打飞"选一条，都不需停格/慢镜卡死）
  · 力学真实流（灵笼路线 · 默认推荐）：克制慢镜，被击者【快速拖出画面/结实砸地撞穿结构】，spacing 骤然拉大、身形大幅度炸开，配白闪震镜——"还没反应就被打出去"，干脆不拖泥带水
  · 炫技慢镜流（日式路线）：命中后叠一个命中顿微升格（或名场面大升格），被击者头发衣摆飘动着漂移飞出，配能量拖尾+音乐推顶，延长冲击回味——★ 绑流动元素+ramp、别裸停；名场面级最炸那次全片 1 回。
  ⚠ 两派共同前提：命中前必有半拍 B 类慢拍（蓄力/接招），没有这半拍静，"砰"不成立

▼ 攻防往复 · 招式链模板（进入战斗后按此串联，保证节奏密度）
  · 基本回合单元：攻 → 挡/格 → 反制 → 瞬移/闪避 → 再攻，五拍一循环，每拍 0.2-0.5s
  · 连招串接：主攻方连续 2-3 招不停顿，受方用一个身法/残影整体化解后立即瞬身反打，绝不各打各的
  · 密度标准：每 2 秒内至少完成一个完整攻防回合（≥3 拍）+ 一次瞬移跳位
  · 句式：多用顿号/短逗号串联动词。范例——「灼刃劈下、抬臂硬挡迸火线、瞬身绕后、残影撩腕、空翻卸力、反手连斩」（6 节点仅 2 秒，含 1 次瞬移）
  · 反面教材：单句只写一个动作再配三行环境形容词 → 立刻拖慢，禁止

本模版刻意不放"标准成品案例"——一旦给出一条完整范例，模型不学方法、只整段照抄里面的具体招式（如"三重残影同时扑向三个方位""坍缩的能量光核""贯穿云层能量光柱"），导致每条视频都套同一老三样、千篇一律。

铁律：每次生成，招式必须结合【当前角色的身体条件 / 明确武器 / 战斗装备 / 材质 / 世界观】现场设计。从弹药库取的是"招式类型"（投射 / 追踪 / 范围 / 近身 / 突袭 / 蓄力大招）与"作画手法"（瞬移 / 残影 / 白闪震镜 / 集中线），不是"成品招"。同一个"瞬身俯冲"，机兽用獠牙面甲喷能量、龙用吐息、机甲用兵装、剑客用居合坠斩、无武器武者则用膝坠/肘压/掌底轰击——落点必须各不相同。

⚠ 严禁套用任何固定招式模板，尤其别每条都写"三重残影 / 坍缩核心 / 贯穿云层能量光柱"这老三样。检查参考图给的独有战斗部件（獠牙 / 面甲 / 尾 / 翼 / 鬃毛 / 护甲 / 义肢 / 兵装挂点），至少让 1-2 个招式从这些部件长出来；茶杯、酒杯、书卷、餐具、普通首饰等生活道具不在此列。无独有战斗部件时，改从角色的体型、重心、关节链、步法与格斗流派现造招式，不得强绑生活道具。

【处理流程 S1–S4】

S1 · 深度拆解：分析主角职业（敏捷型 / 重装型）、武器特性、番剧画风、环境要素及核心冲突点；先完成【武器 / 工具 / 生活道具】分类，若无明确武器则明确写出“默认空手格斗”及道具在镜头1的因果退场方案；再从参考图世界观反推敌方势力母版，设计第一阶敌群、第二阶精英、第三阶首领的轮廓/主色/武器/能力差异。
S2 · 叙事编排（多图时含重构）：确定最佳叙事顺序，识别首尾帧与核心作画帧，设计连贯动作流 + 瞬移跳位路线 + 敌人分批入场/退场路线；同步画出 E1→E2→E3 敌人压力曲线与 S1→S2→S3→S4 场景破坏曲线，确保高能碰撞点均匀升级、动作不间断。
S3 · 编剧创作：按 R7 写出短故事，中段密集穿插高燃名场面；每一阶敌人都必须提出新难题并逼出主角新机制，结尾由最强敌与最大场景反馈共同完成高潮。
S4 · 视觉渲染与输出：从【弹药库】取动词、敌人反馈、场景规模、作画反馈、疯切运镜、特效素材，按四阶段编排成 15s 连续篇章提示词。
