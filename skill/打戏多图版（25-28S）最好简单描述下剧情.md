# AI 战斗剧情简介 → 16格文字镜头大纲 → 分镜图 → 原图返修 → 视频提示词工作流模板

## 一、模板用途与核心原则

用户上传角色参考图和场景参考图后，严格分三个阶段完成任务。先用低成本文字把剧情、节奏和镜头讲清楚，再生成分镜图；不要一上来就让图像模型替代导演设计。

### 阶段一：只完成剧情简介与16格文字镜头大纲

1. 识别并锁定角色、服装、武器、能力和场景。
2. 用2—4句话说明人物目标、冲突、战术变化和结尾，先让用户理解“这场打斗在讲什么”。
3. 输出简单、可读的16格文字镜头大纲；每格必须包含建议时长、景别/机位、可见人物、画面动作和衔接作用。
4. 先检查文字大纲的节奏、景别变化、空间因果和总时长，不生成图像，也不生成视频提示词。
5. 把剧情简介与16格文字大纲发给用户，明确询问是否确认，然后立即暂停。

### 阶段二：用户确认文字大纲后，才生成并验收分镜图

1. 只有用户明确确认文字大纲或明确说“可以生成看看”后，才调用图像生成工具。
2. 严格以已确认的16格文字大纲为动作、景别、人物显隐和镜头顺序基准，生成一张4×4黑白分镜图。
3. 必须打开实际成图逐格检查；自检不合格时，优先把当前整张分镜图作为编辑目标直接返修。
4. 返修指定画格时，锁死其余15格，直接编辑当前整张原图；当前工具不支持时必须说明限制并暂停，不得自主改用独立画格生成与拼接。
5. 自检通过后，把分镜图和简短检查结果发给用户，询问是否确认，然后立即暂停。

### 阶段三：用户确认分镜图后，才生成视频提示词

1. 只有用户明确回复“没问题”“确认”“通过”“就用这版”或“可以生成视频提示词”后，才进入阶段三。
2. 根据用户确认过的分镜图逐格生成对应视频提示词。
3. 不得根据未确认的文字大纲或未确认的分镜图提前生成视频提示词。
4. 如果用户要求修改任意画格，必须退回阶段二：直接编辑原分镜图、重新自检、重新发图、再次等待确认。

### 绝对门禁

> 先讲清剧情和16格文字镜头，再等用户确认；确认后才出图；出图后必须验图并再次等用户确认；最后才输出视频提示词。

在文字大纲尚未确认时，禁止：

- 调用图像生成工具；
- 宣称已经开始生成分镜图；
- 输出视频提示词。

在分镜图交付并等待确认的同一轮回复中，禁止附带以下内容：

- 16条逐镜视频提示词；
- 统一视频视觉前缀；
- 已经开始生成视频的表述；
- 把“自检通过”当成“用户已经确认”。

模板适用于双人决斗、多人遭遇战、追逐、刺杀、机甲战、武侠战斗、奇幻法术战等题材。

## 三、执行状态机

模型必须先判断当前对话处于哪个状态，并且一次只执行当前状态允许的工作。

| 状态 | 触发条件 | 允许执行 | 完成后的下一步 |
|---|---|---|---|
| S1 输入与锁定 | 用户刚上传参考图或资料 | 看图、分配图片职责、锁定角色、武器、场景、战斗目标和结局 | 进入S2 |
| S2 文字镜头大纲 | 输入已锁定 | 输出2—4句剧情简介与16格文字镜头表；检查时长、节奏、景别、人物显隐和因果链 | 进入S3 |
| S3 等待大纲确认 | 文字大纲已输出 | 只接收确认或修改意见；不得生成图像 | 用户确认进入S4；用户修改则回到S2 |
| S4 分镜图生成 | 用户明确确认文字大纲 | 严格按已确认大纲调用图像工具，生成4×4黑白分镜图 | 进入S5 |
| S5 图像自检与原图返修 | 已经得到实际图像文件 | 打开并逐格检查；不合格时直接编辑当前整张原图并锁定其他画格 | 合格进入S6 |
| S6 等待分镜图确认 | 图像自检已经通过 | 发送图像、检查摘要并询问用户；必须暂停 | 用户确认进入S7；用户修改则回到S5 |
| S7 视频提示词 | 用户明确确认分镜图 | 逐格读取已确认图像，生成图片职责声明、统一前缀、16条视频提示词和连续性检查 | 完成交付 |

### 用户确认的有效表达

确认必须结合当前状态理解。用户刚看完文字大纲时，以下表达可视为“大纲确认”；用户刚看完分镜图时，以下表达可视为“分镜图确认”：

- “没问题”；
- “确认”；
- “通过”；
- “就用这版”；
- “可以，生成看看”（仅在S3表示同意生成分镜图）；
- “可以生成视频提示词了”。

以下表达不能自动视为确认：

- “继续”；
- “先看看”；
- “差不多”；
- “还行”；
- 没有明确评价图像、只提出其他问题。

遇到模糊表达时，根据当前状态只追问一个问题：

- S3：“这版剧情和16格文字镜头大纲是否确认？确认后我再生成分镜图。”
- S6：“这版分镜图是否确认？确认后我再生成对应的视频提示词。”

不得跳过任一确认门禁。

## 四、阶段一总控提示词：先讲清剧情与16格文字镜头

将用户上传的角色图、场景图与下面提示词一起交给支持看图的模型。当前阶段只做导演设计，不调用图像生成工具。

```text
你是一名专业动作导演、电影分镜师和动画导演。

当前只执行阶段一：输出简短剧情简介与16格文字镜头大纲，等待用户确认。不要生成分镜图，不要生成视频提示词。

一、参考图职责与视觉锁定

根据用户上传顺序，明确哪张图是角色A、哪张图是角色B、哪张图是场景，其他图片分别承担什么职责。不要把多个角色融合，不要增加新角色。

提取并锁定：
- 角色A的身份、体型、服装、盔甲、主要武器、能力和战斗语言；
- 角色B的身份、体型、服装、盔甲、主要武器、能力和战斗语言；
- 场景的地形、建筑、空间层级、关键地标、可破坏物和光线方向。

二、先定义“这场战斗在讲什么”

先用2—4句话说明：
1. 角色A想完成什么具体目标；
2. 角色B怎样阻止或追击；
3. 正面对抗为什么不够，角色如何改变战术；
4. 场景或道具怎样参与因果链；
5. 最终采用什么结局、反转或悬念。

如果角色只是无目的地互打，必须先补出一个可视化目标，例如夺门、护送、抢夺、逃离、阻止仪式、守住高地或迫使对方暴露弱点。

三、避免“16格都在双人互指武器”

默认镜头配额如下，可根据题材上下浮动1格，但双人完整同框不得成为多数：
- 环境空镜或环境主导：2—3格；
- 单人全身或单人动作：4—6格；
- 主观镜头、身体局部、武器或道具特写：3—5格；
- 双人完整同框：3—5格，最多6格；
- 直接武器互指、正面对撞或标准左右对峙：最多3格。

180度轴线只负责方向连续，不等于每格都必须同时出现两个人。单人镜头、主观镜头、空镜和环境镜头也必须遵守行动方向。

相邻两格必须至少改变一项：景别、机位高度、镜头方向、人物显隐、运动速度、空间层级或叙事信息。禁止连续三格使用相似的双人中景对打构图。

四、节奏与因果链

总节奏保持“慢—快—停—爆—静—高潮—定格”，但每个阶段必须改变战术目标或空间关系，而不只是换一个挥砍动作。

- 第1—4格：环境与单人登场，建立目标、距离和危险；
- 第5—8格：第一次加速，试探失败后转向环境、道具或战术弱点；
- 第9—12格：空间失衡、坠落、追逐或反制；安排一个明显静止或机械停顿；
- 第13—15格：隐藏手段揭示、环境因果兑现与高潮位移；
- 第16格：完全静止，用结果、反转、影子、空位、残留物或新威胁形成记忆点。

每次动作必须有原因和结果：某格触发的破坏、伤势、落点或道具状态，要在后续格继续存在。高速动作后必须留出可感知停顿。

五、16格文字镜头大纲格式

先输出2—4句剧情简介，再输出下表。总时长控制在用户指定范围；未指定时按25—28秒设计。

| 格 | 时长 | 景别与机位 | 可见主体 | 画面动作 | 衔接与作用 |
|---|---:|---|---|---|---|
| 1 | {{秒}} | {{景别、角度、运动}} | {{环境 / A / B / 双人 / 局部}} | {{本格可见动作}} | {{建立、触发或衔接什么}} |
| 2—16 | {{逐格填写}} | {{逐格填写}} | {{逐格填写}} | {{逐格填写}} | {{逐格填写}} |

镜头描述要简单、具体、可画。每格只保留一个主要视觉事件，不要把一整段复杂动作塞进一格。

六、文字大纲自检

- 总时长是否落在目标范围；
- 是否存在明确目标、阻力、战术变化和结尾；
- 是否有环境或道具参与战斗因果；
- 是否包含空镜、单人、局部/主观和双人镜头；
- 双人完整同框和武器互指是否超量；
- 相邻镜头景别与机位是否有变化；
- 是否至少有一次高速、一次骤停和一次高潮；
- 前一格结束状态是否能连接下一格。

七、阶段一交付门禁

只输出：
1. 图片职责简表；
2. 2—4句剧情简介；
3. 16格文字镜头大纲；
4. 一句确认问题：“这版剧情和16格文字镜头大纲是否确认？确认后我再生成分镜图。”

发出问题后立即停止，不调用图像生成工具。
```

## 六、阶段二图像视觉自检

### 6.1 检查方式

必须检查生成后的实际图像，并按照左到右、上到下逐格查看。检查结果分为“硬性通过项”和“质量项”。只要任一硬性项失败，整张图不得交付。

### 6.2 硬性通过项

- [ ] 总画幅是16:9横向，目标尺寸2048×1152。
- [ ] 正好4列×4行，共16格。
- [ ] 16格大小相等，没有合并格、缺格、多格或不规则格。
- [ ] 图中只有用户指定的主要角色，没有额外人物或重复人物。
- [ ] 每格可见主体符合已确认文字大纲：空镜无人、单人镜头不补第二人、局部镜头不擅自变成双人全身。
- [ ] 图1、图2等参考图职责没有混淆，多个角色没有融合。
- [ ] 角色脸部、体型、发型、头饰、服装和盔甲在16格中保持可识别一致。
- [ ] 主要武器类型、长度和持握关系保持一致，没有消失或变形。
- [ ] 场景类型与关键地标保持一致，没有无理由切换场地。
- [ ] 角色A与角色B的左右关系符合180度轴线，没有无理由换边。
- [ ] 16格动作按左到右、上到下能够连续阅读。
- [ ] 前一格的结束姿势可以连接后一格的开始姿势。
- [ ] 至少有一次明确静止和一次高潮，快慢节奏能从画面读出。
- [ ] 双人完整同框没有成为多数，连续三格没有重复使用相似的双人中景对打构图。
- [ ] 最后一格具有清楚结局、反转或悬念记忆点。
- [ ] 没有严重肢体畸形、穿模、角色融化或无法辨认的接触点。

- [ ] 没有字幕、对话、格号、数字、拟声词、标志或水印。

### 6.3 质量项

- [ ] 每格景别和机位有变化，但整体视觉语言统一。
- [ ] 环境空镜、单人、主观/局部/道具和双人镜头形成可读交替，而不是16格都由两个人承担信息。
- [ ] 环境或道具至少一次真正改变局势，并在后续画格保留因果结果。
- [ ] 动作剪影清楚，角色没有被烟尘、速度线或特效遮挡。
- [ ] 攻击能看出起势、接触、受力和余势。
- [ ] 高速段之后有可感知停顿。
- [ ] 环境破坏沿受力方向发生，并在后续格中保持。
- [ ] 线条轻盈、克制，没有厚重黑块和大面积脏灰。
- [ ] 画格边缘保留安全空间，头部、武器和关键接触点没有被裁切。

### 6.4 返修规则

1. 返修前先打开当前整张分镜原图，记录目标格号、所在行列、错误和必须保留的内容。
2. 如果原图位于本地文件系统，必须先实际打开或载入该图，使编辑工具能够看到真实像素；不能只把文件路径写进提示词。
3. 返修时把当前完整16宫格原图作为唯一编辑目标，同时携带必要的原始角色图和场景图；使用图像编辑模式直接修改原图。

## 十四、完整推荐执行顺序

### 阶段一：先确认剧情与文字镜头大纲

7. 检查镜头配额：双人完整同框不得成为多数，武器互指或正面对撞不超过3格。

9. 把剧情简介与文字大纲发给用户，询问是否确认。
10. 停止，不生成图像，等待用户回复。

### 阶段二：按已确认大纲生成并验收分镜图

6. 不生成独立替换画格，不程序化拼接，除非用户明确要求。
7. 每次返修后重新打开整张图，对比非目标画格并重跑完整自检。
8. 合格后把图像和自检摘要发给用户。
9. 询问用户是否确认。
10. 停止，等待用户回复。

1. 记录具体格号和修改要求。
2. 打开当前完整分镜原图并进入图像编辑模式。

1. 收到用户明确确认。

8. 交付提示词；不自动生成视频，除非用户另行要求。

### 后续视频制作建议

1. 每个画格单独作为对应图生视频镜头的起始参考图。
2. 每镜建议0.8—3秒，复杂动作宁可拆镜，不一次生成过长片段。
3. 将上一镜头实际生成视频的末帧作为下一镜头补充参考，可改善连续性。
4. 普通对峙保留环境声和呼吸感。
5. 高速动作使用短镜头与动作匹配剪辑。
6. 关键接触点前后保留2—4帧视觉停顿。
7. 高速段结束后安排1.5—2.5秒安静镜头。
8. 最后一镜停留2—3秒，强化反转或悬念。
