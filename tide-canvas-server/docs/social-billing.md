# 下载与内容拆解积分

后台「系统配置 → 内容拆解」增加两个受保护的基线键，启动时自动补齐，不覆盖已有值：

| 功能 | 配置键 | 默认 |
| --- | --- | --- |
| 视频下载 | `social.download.pointCost` | 1 积分/次 |
| 每位用户每日下载上限 | `social.download.dailyLimit` | 1 次/天 |
| 内容拆解（作品/账号） | `social.analysis.pointCost` | 1 积分/次 |

只接受 1–100000 的整数，不允许设为零或负数。保存后新执行立即使用新价格；前端随状态接口显示费用。请求可携带 `expectedPointCost`，与现价不同则拒绝执行并提示更新价格，不扣费。

## 计费边界

- 每日下载上限全站统一配置、按用户独立计算，所有下载平台共用名额。以发起下载的北京时间自然日为准，零点重置。下载解析前占用名额，成功后保留；进行中、待下载也占用，失败退款后释放。历史删除不释放次数，旧版成功下载也计入当天用量。已有下载的继续传输、预览和浏览器本地再次保存不占新名额；隔日退款只释放原日期的占用。
- 后端在同一用户行锁内完成次数检查、新执行记录和积分扣除，拒绝超限请求时不扣积分、不解析视频。幂等重试仍返回原执行，不重复计次。前台显示当前价格、余额与每日剩余次数，后台提高或降低上限后新请求立即生效。

- `/inspect` 和 `/downloader/resolve` 在外部解析调用前原子创建执行记录、扣除余额、写入积分流水；余额不足返回业务码 `2001`，不访问平台。
- `clientRequestId` 绑定用户及操作参数；重复请求不会多扣或再次访问平台，更换参数复用同一标识会被拒绝。网络结果不明、网关 502/504、请求超时或响应体损坏时客户端保留标识重试。余额已扣至 0 时仍可重试原操作获取结果；更换链接、分析类型或账号后不能借此绕过新执行的余额检查。
- 下载解析和文件传输合为一笔执行。凭证跨实例只允许一次传输；未下载过期、准备失败或连接中断退还原价。已接收文件的再次保存及本地预览不收费。历史中未过期的待下载执行可以直接继续。
- 免费再次保存仅限当前页面仍保留的已接收文件。刷新、关闭页面或替换本地文件后，历史记录不能充当永久免费重下凭证；重新发起下载按当前价格和次数限制执行。下载凭证最长有效 5 分钟，用于开始下载；已开始的传输有独立的一小时时限。服务器完成交付后，浏览器是否成功写入用户磁盘不可由服务器确认，本地保存失败不自动触发退款。
- 内容拆解页面按次获取平台数据快照，展示账号/作品资料、指标、图表和作品列表。账号与单个作品均不再提供右侧 AI 报告面板；新解析不会自动创建报告，恢复历史快照也不会加载或轮询关联的 AI 任务。
- 既有 AI 报告的服务端兼容逻辑保留：通过用户、记录、技能运行、任务关联认领一次报告权益，不另扣模型价。仅三个内置分析技能的文本报告可使用该权益。既有报告生成失败或取消会退回关联的拆解费用，重试不能复用已退款权益。
- 历史快照、已有报告、已保存文件不发起新计费。显式重新获取平台数据是一次新执行。既有历史记录保持未计费状态，不追溯扣款；需要生成新报告时必须重新获取数据并按当前价格执行。
- 从生成记录中主动打开已有报告可查看原任务；重新编辑保留链接，返回平台数据解析入口并提示计费，不复用已消费或已退款的报告权益。

## 可靠性与运维

执行记录保存 `point_cost`、`refunded`、幂等请求及一次报告任务关联。技能运行另存不可由客户端输入修改的 `social_activity_id`，计费认领、禁止重试和退款均依据该绑定；绑定异常时拒绝运行，不回退到模型价格再次扣费。失败按记录中的原价退款，后台调价不会影响历史退款。余额修改与流水沿用统一 `points` 事务及退款收据，重复失败回调不会多退。

进程启动及每分钟恢复一次：处理超过 10 分钟的解析、未使用且过期的下载凭证、超过 61 分钟的下载、失败/取消报告及未完成的退款。候选记录加锁后再次校验状态，避免退款与开始下载、完成任务争用。正常失败同步退款；强制终止的任务在恢复窗口内补退。

读取下载历史时也会恢复当前用户的过期或中断下载，状态和退款在同一事务提交；退款流水写入失败时全部回滚，保留后续补退能力。已失败但未确认退款的付费下载继续等待退款状态（仍受总等待时限约束）。迟到的完成回调不能将已退款记录重新标记成功。

前台历史及后台分析记录均显示当次积分/退款状态；积分流水关联执行记录 ID。下载票据及私有快照仍仅对记录所有者开放。
