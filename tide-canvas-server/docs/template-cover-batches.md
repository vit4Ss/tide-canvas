# 创作模板批量封面

## 设置默认图片模型

后台「模型管理」选择图片模型，进入「配置 → 生成能力」，开启「创作模板批量封面」并保存。

- 新字段 templateCoverBatch 默认关闭；历史图片模型不会自动开启。
- 需要已上架、正常且支持文生图的图片模型。
- 多款开启时，按模型管理的排序选择第一款可用模型。确认弹窗会显示实际模型名称及积分。
- 与全局图片主模型、蒙版模型和模板自身的视频/图片生成模型分开，不改变原创作台或单张封面功能。
- 重新同步中转站模型目录会保留该本地配置。

## 批量操作

在「创作模板」筛选模板类型、图片/视频、分类、状态及关键词，点击「批量生成封面」。

1. 服务端查找当前筛选下所有缺少封面的模板，跨分页，一批最多200张。
2. 弹窗显示数量、默认图片模型、单张积分、预计总积分和可用积分。
3. 明确点击「确认生成」后才创建任务。打开弹窗、检查数量和读取进度均不收费。
4. 后台逐张生成，成功后只更新空的 cover_url；不修改私有提示词、模板参数、使用次数或上架状态。
5. 可以关闭弹窗或刷新浏览器，再点击批量按钮查看进度。停止按钮只停止后续图片，已提交的图片继续执行和结算。
6. 部分失败不自动重新付费生成；处理结束后可重新检查仍缺失的封面，再确认新的批次。

封面是主题示意图，提示词只取模板名称、分类和展示介绍，不复制私有执行配方。

## 计费与恢复

- 使用原有生成、积分流水和失败退款链路；费用来自提交批次的管理员账号。
- 开始前要求可用积分足够，扣除冻结/预占积分后计算；不预扣整批，逐张按真实模型价格扣分。期间被其他任务用掉积分时，后续提交可能停止。
- 模型记录、参数和价格在确认时锁定。后续停用开关、下架、维护或配置价格变更会阻止新的提交，需要重新确认。
- 正在运行的批次在全站互斥，避免多个页面或管理员重复补同一批封面。
- 批次和每张图片的任务关联持久化在 template_cover_batches 表。单任务使用稳定请求编号和完整请求指纹，响应丢失或进程重启后恢复原任务，不创建新的付费请求。
- 服务重启后由新进程接续，最多等待原45秒租约过期。已提交任务的恢复和超时退款沿用原生成服务。
- 批次状态和自动停止的写入也核对执行租约；旧进程不能停止新进程已接手的批次。停止队列逐项保存检查进度，后续查询超时不会丢失之前已确认的跳过结果。
- 生成过程中若有人添加封面、修改标题/介绍/分类或删除模板，不覆盖其改动。已完成图片保留在批次结果中，可自行采用。
- 停止状态、执行租约、模板快照与扣分在同一事务中核对。停止成功后不会再受理新的付费图片；已受理任务仍可恢复。重复停止是安全的。
- 提前打开的编辑表单保存时，如果用户未改封面，会保留后台刚补齐的封面；双方均修改封面时返回冲突，保留表单内容。判断兼容存储地址到CDN地址的读时改写。
- 查看已有批次不重新报价，即使模型已关闭或新报价暂不可用，也能读取进度并停止后续任务。
- 管理员只能查询和停止自己创建的批次；接口还受原有创作模板管理权限约束。

## 部署

更新后端、前端。后端启动时自动迁移新表，不需要额外服务、脚本或环境变量。默认没有任何图片模型开启此功能，需要管理员主动开启。

## 验证范围

自动测试覆盖默认关闭、非图片/非文生图拒绝、模型优先级、报价变化、冻结积分、重复请求、跨进程租约、丢响应恢复、部分失败、停止后续、人工封面保护、权限隔离，以及真实生成服务的计费和失败退款。浏览器测试覆盖开关保存、预估确认、进度恢复和移动端布局；使用模拟供应商，未发起真实付费生成。
