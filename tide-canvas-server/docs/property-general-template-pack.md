- 时长30秒，比例9:16，清晰度720p，15个完整镜头，每镜2秒。

## 配方适配与原文保留

原文包含完整分镜，也包含客户替换区、随机重写入口和后期落版要求。执行版适配本站只上传素材的流程：保留原推荐风格、15镜顺序、5组动作、口播和拟音，去掉二次编写指令；未提供品牌、服务或岗位资料时按通用情景演示处理，不朗读占位符或编造联系方式。

夜间照明场景明确保持夜间光线；团队招募没有岗位资料时不宣称存在已发布岗位。源文件原有的个人信息脱敏、不虚构服务承诺、安全作业和维修时间跳切要求保留。清晰度由模板配置控制，运营改用1080p时不会与固定720p文字指令冲突。

原始30份TXT、3份公共说明TXT、JSON和HTML总览共35个文件逐字节保存于后端私有目录：

`internal/handler/studiotemplate/content-packs/property-general-v3/source/`

HTML仅作来源归档，不执行其中脚本、不作为前端页面。`catalog.json`记录原始路径、SHA-256、风格元数据和执行配方；Git关闭原文件的换行转换以保留BOM与原始CRCRLF。公开模板接口不返回提示词和原始来源资料。
