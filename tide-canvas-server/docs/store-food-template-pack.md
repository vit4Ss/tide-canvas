# 门店与食品厂 · 20套无需名称版 v002

内容来自用户提供的 `门店与食品厂_20套_无需名称版_v002.zip`，包含10个行业，每个行业各有15秒、30秒版，总计20个独立视频模板。合集文本是同一批内容，不重复创建模板。

| 分类 | 行业 | 版本 |
| --- | --- | --- |
| 餐饮探店 | 火锅店、烧烤店、家常饭店 | 各15秒、30秒 |
| 门店带看 | 美甲店、按摩休闲店、理发店、口腔机构、眼镜店 | 各15秒、30秒 |
| 食品工厂 | 辣椒酱食品厂、烘焙糕点食品厂 | 各15秒、30秒 |

所有模板采用9:16、多模态参考视频模式。保留原文的镜头时间轴、中文短对白、人物一致性要求，以及“不填写名称、不朗读招牌、不虚构实际生产线/诊疗效果”的说明。15秒5镜、30秒10镜，未把30秒配方压缩为15秒。

## 使用方式

部署本次后端后，启动时自动补齐20个**草稿**。后台 → 创作模板 → 灵感做同款 → 视频 → 草稿/已下架，可按行业搜索。

1. 编辑模板，核对提示词、上传用途和可选位置。
2. 选择支持对应时长、多图参考的模型，或用「检查生成配置」自动选定符合规格的模型。后端仍校验该模型允许的图片数量、提示词长度与价格。
3. 用真实素材试做，填写封面图片，或点击「AI 生成封面」生成示意图；成功后自动回填，保存模板后再上架。视频预览为选填，可不提供。

压缩包只有文字，没有封面和成片；默认导入仍是草稿，不自动上架或自动调用付费模型。后台可主动使用AI生成封面，按所选图片模型扣除管理员账号积分；回填并保存后生效，用户端会说明只有封面示意。若生成期间手动换了封面，则保留手动选择，可展开面板采用生成结果。草稿中的模型保持未指定，积分按运营最终选定的模型与报价计算。

切换模型时保留模板原有的视频时长。所选模型不支持30秒时，页面明确提示不兼容，不会改成5秒或15秒；切回自动选择也保留原规格。如果运营主动改短时长，需要同步调整分镜提示词。自动选择会检查候选模型的实际默认输出和按次价格，跳过无法计价的候选；已明确指定的模型配置异常时直接报错，不自动换线路。

## 图片位置

每套配置6个上传位置，门店的门面和店内全景必填，其余选填。食品厂的入口、接待展示区、真实产品与包装、实际生产车间必填，头像和设备工序细节选填。

| 位置 | 门店 | 食品厂 |
| --- | --- | --- |
| 1 | 门面照片，必填 | 厂区入口，必填 |
| 2 | 店内全景，必填 | 接待与展示区，必填 |
| 3 | 本人头像，选填 | 本人头像，选填 |
| 4 | 菜品、作品或产品，选填 | 产品与包装，必填 |
| 5 | 其他实际空间，选填 | 实际生产车间，必填 |
| 6 | 细节图片，选填 | 设备与工序细节，选填 |

不上传头像时使用原文的虚构成年讲解人方案。用户只上传素材，不需要修改提示词或填写名称。

后台执行配方使用 `{{image:1}}` 至 `{{image:6}}` 绑定固定位置。前台同时提交 `imageIds` 和对应的 `imageSlots`（从1开始）。例如上传位置1、2、4、5时，模板中的 `{{image:4}}` 会变成本次实际第3张图 `@图3`，`{{image:5}}` 变成 `@图4`；未提供的头像明确标记未上传，不会指向产品图。

普通「图片1」自然语言不会自动改写；有可选位置的自定义配方应使用上述占位符，并写明缺图时的处理方式。原文中所有 `@图N` / `图N` 已在导入时转换，原始文件另外完整保留，可审计对照。

有可选图片时，保存和生成会拒绝混用「图片3」「@图3」等未绑定编号，提示改用固定位置占位符。上架前检查会计算包含缺图说明的提示词长度上限；自动选模型也会跳过字数容量不足的候选，避免“全图检查通过、少传头像后超限”。
