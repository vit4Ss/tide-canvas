# 创作台风格与灵感

创作台 `/studio` 的图片和视频模式都提供「风格主题」「灵感做同款」「生成记录」。

- 风格主题：将视觉方向提示词与用户的主体描述组合；切换风格时只替换未被手动修改的旧风格段落。移除风格保留用户描述。
- 灵感做同款：使用具体成品、完整提示词和素材要求。替换已有提示词前二次确认。
- 应用模板只配置输入，不自动生成或扣积分。生成继续使用现有模型、参考素材校验、报价、积分扣费和失败退款流程。
- 封面和成片用于预览，不自动发送为用户参考素材。素材要求在提交前检查；不满足时不会发起付费请求。
- 图片卡片使用渐变遮罩，选中时缩略图飞入左侧模板区域。视频仅在悬停时播放或由用户在详情中主动播放；减少动态效果偏好会禁用飞入和悬停自动播放。

## 后台运营

入口：后台 → 创作模板（`/admin/studio-templates`），沿用 `admin.inspiration` 权限。

1. 选择风格/灵感、图片/视频，点击新建。
2. 填写名称、分类、简介、完整提示词与「用户需要上传什么」。
3. 选择创作模式，设置最少图片/视频/音频数量。多模态参考才能要求视频、音频输入。
4. 上传封面；视频模板另上传可播放的成片。也可填写 HTTP/HTTPS 媒体地址。
5. 可设置推荐模型、建议比例/分辨率/时长/质量。用户模型必须支持相应模式和参考输入，参数不支持时沿用该模型可用设置。
6. 默认保存为草稿。选择上架后才对用户可见；排序数值越小越靠前。支持编辑、下架和删除。

「从用户作品导入」另需 `admin.generations` 权限：可以按用户 ID 或任务 ID 查找已完成的直接图片/视频生成，导入成品、用户公开提示词及允许的参数为灵感草稿。重复导入同一任务会打开已有模板，不产生重复内容。

删除导入的灵感后可以再次导入，重新生成未上架的草稿。切换首尾帧模板保留首帧/尾帧位置；当前模型隐藏的素材或超过目标容量的素材会在移除前提示。建议参数使用目标模型的实际枚举值，避免大小写差异造成配置回退。

不复制源用户身份、私人参考图/视频/音频、供应商报文或 Skill 工作流内部提示词。导入后需运营核对公开内容、署名、成片可用性和素材要求再上架。视频导入需补充封面。预览仅说明创作方向，不能保证不同模型得到完全相同的细节。

原画布风格库、旧灵感合集和 Skill 保持各自用途；这个模板目录专门服务创作台。

## 部署与验证

部署主站后端和前端。后端启动时自动迁移 `studio_template` 表，无需新增环境变量。
首次启动安装 6 个由内置 image_gen 实际生成的原创图片示例，包含黏土、纸艺、电影肖像、东方绘画、换装和产品广告，署名为「FlowLight 原创示例」，使用次数从 0 开始。
另提供 2 个视频分镜封面草稿；它们是静帧，没有伪装成可播放的视频，运营需补充真实成片再上架。
示例的提示词、素材要求、封面与建议参数均可编辑。后续重启不会覆盖运营修改，也不会复活已删除的示例。

网页素材在 `tide-canvas-web/public/studio-samples/v1/`，随主站前端镜像部署；原始生成提示词见同目录 `generation-prompts.json`。配套模板数据在后端 `internal/handler/studiotemplate/samples.json`，不依赖外部随机图片服务。WebP 仅做编码压缩，保持生成图的原始尺寸。

- 公开列表/详情：`GET /api/studio-templates`、`GET /api/studio-templates/:id`，仅返回已上架内容。
- 使用计数：`POST /api/studio-templates/:id/use`，需要登录且限流。
- 后台 CRUD：`/api/admin/studio-templates`。
- 来源查询/导入：`GET /api/admin/studio-templates/sources`、`POST /api/admin/studio-templates/from-task`。
- 服务端用例覆盖草稿隔离、下架/删除、输入约束、导入幂等、来源隐私和模块权限。
- `tide-canvas-web/tests/studio-templates-browser.mjs` 使用隔离模拟接口验证套用、素材不足不付费、布局、后台保存与导入；不会调用实际生成服务。
