# 灵感和模板

批量补封面：[模型开关、批量操作及恢复说明](template-cover-batches.md)。

新增内容包：[AI超市团购与宣传50套](groupbuy-promo-template-pack.md)，部署后端后自动添加为视频草稿，与已有[门店与食品厂20套](store-food-template-pack.md)独立保留。

FlowLight 主站通过 `/templates` 展示图片、视频模板，`/templates/:id` 提供「看效果 → 上传素材 → 确认积分 → 生成同款」的独立流程。入口在主站导航和工作区侧栏；创作台 `/studio` 保留自由创作，不再展示模板库或把模板提示词填进编辑器。原有 `/inspire` 灵感合集与 Skill 功能保持独立。

## 用户流程

页面沿用 FlowLight 深色主题。列表将成品、名称和效果说明放在同一张作品卡中，素材要求与「做同款」紧邻展示；宽屏使用更紧凑的多列浏览，窄屏保留两列图片模板。视频筛选使用横向预览比例。

生成页在桌面上分为完整效果预览与集中操作区，图片上传位置并排显示；手机端使用本模块专属的紧凑导航，示例默认折叠，首屏可开始上传。操作区保持正常文档流，不使用会遮挡素材的吸附按钮。生成成功后主预览自动展开为用户结果，支持与模板示例切换，下载和再次使用入口直接显示在操作区。页面头部已有生成记录入口，因此本模块不再重复显示全局悬浮历史按钮。

- 用户选择模板后，只上传要求的图片、视频或音频，不填写提示词，不选择模型参数。音频作为多模态视频模板的参考素材使用。
- 每个上传位置保留语义和顺序，首尾帧模板明确区分首帧、尾帧，允许有意使用同一张图片作为两帧；其他多图片位置拒绝重复文件，避免通用去重导致配方缺失素材；多模态无固定要求的模板至少上传一种素材。
- 素材用途由后台 `inputLabels` 明确配置，例如「人物照片」「服装图片」，不通过标题猜测。未配置时回退为编号。上传前显示常见格式与当前模型的大小限制。
- 替换上传成功后才覆盖旧素材；失败保留旧文件并提供重试，上传期间不可移除该槽位。
- 生成前的草稿按账号、模板及素材结构隔离，本机草稿的恢复有效期为7天，不保存文件内容、密钥或提示词。恢复时重新核验文件归属和有效性；网络核验失败保留引用并允许重试，模板素材角色改变则要求重新选择。此期限不改变服务端文件保存政策。
- 列表关键词、类型、分类及分页保留在 URL，进入模板时保存列表位置，浏览器返回和页面返回均可恢复浏览上下文。
- 上传前读取不产生任务的配置预览，显示基础费用与有效输出规格。素材齐全后向服务端询价，确认实际模型、分辨率、比例、时长、画质与总积分，参考视频附加费单独说明。报价失败显示明确错误与重试；上传和询价不扣积分，点击「生成同款」才创建付费任务。
- 显示真实任务进度、完成结果与失败原因。提交结果不明确时检查原请求，不新建重复付费任务；刷新页面恢复当前账号的任务。
- 模板或价格变化后要求重新确认积分；模板下架、素材不足、素材类型错误、其他账号的素材、模型不兼容在扣费前拒绝。已受理的任务仍可按原请求恢复；模板下架后，原页面保留已提交任务的进度、结果与恢复入口，也可从生成记录查看。
- 「下载作品」复用已有文件授权票据与附件下载代理，真正触发浏览器下载；「查看原文件」另作普通链接。也能从共享的生成记录查看。创作台历史中的模板作品再次生成或编辑时回到模板页面，不会把空提示词作为普通创作提交。失败退款沿用已有生成链路。

## 提示词与数据边界

普通用户的模板列表和详情使用明确的公开字段，不返回 `prompt`、`modelKey` 或来源任务。客户端提交的是 `templateId`、`templateQuote` 和当前账号上传文件的 ID，服务端查找已上架模板、选择兼容模型并填入私有提示词与参数。

示例封面仍在前端 `public/studio-samples/v1/`；封面生成来源记录移至非公开的 `scripts/studio-sample-provenance.json`，不再作为静态 JSON 发布。如果旧静态路径曾由 CDN 缓存，部署时清理该路径缓存。

任务的公开输入、生成历史和作品说明只保存素材、模板标识及输出参数；生成供应商可能回显的任意 metadata 不进入模板任务的公开结果。原始供应商审计仅保留在原有管理员权限边界内。该策略适用于新版模板任务；不会删除用户以前在自由创作中自行保存的提示词。

报价令牌仅用于检测配方、素材和价格变化，不是客户端指定费用的凭证。生成时重新验证并计算价格，包括开启参考视频计费的模型。模板使用次数只在新任务受理的数据库事务内累计，重复请求不会再扣积分或累计使用次数。

## 后台运营

入口：后台 → 创作模板（`/admin/studio-templates`），沿用 `admin.inspiration` 权限。

1. 选择风格/灵感、图片/视频并新建，填写名称、分类、效果介绍。
2. 填写完整提示词，描述可直接执行的配方；用户界面没有补充提示词入口。
3. 填写「用户需要上传什么」及每个位置的「素材用途名称」；设置创作模式与所需素材数量。只有多模态参考模式接收视频和音频。
4. 上传封面，或点击「AI 生成封面」根据模板介绍生成示意图。视频成片预览为选填；只提供封面时可上架，用户端标注封面示意。展示素材不会自动作为用户参考素材。
5. 配置生成模型、比例、分辨率、时长、质量。点击「检查生成配置」会使用正式生成链路检查可用模型、素材类型/数量及参数，展示实际规格与基础费用；不调用供应商、不创建任务、不扣积分。检查不等于真实成品效果验收。
6. 默认保存为草稿，提示词未写完也可先保存。上架会再次检查配置，明确填写的不支持参数会被拒绝，不会静默替换；留空参数采用模型默认值。自动选择的模型和生效规格在上架时固定，避免模型排序变化导致效果漂移。运行时只发送所选模型已配置的参数。已保存的值若不再属于模型的可选范围，在扣费前提示重新配置，不会静默回退到另一规格。
7. 支持「复制」为独立草稿，保留配方、预览与素材角色，不复制原 ID、来源绑定、使用次数或上架状态；原模板不受影响。上架后可从「用户页」打开使用入口。编辑未保存时关闭或刷新有提醒，检查失败保留所有输入。
8. 图生视频固定1张图片，首尾帧固定2张，文生模式不要求上传，避免后台填出用户无法完成的数量组合。保存后切换到对应媒体/类型并清除旧筛选，避免运营找不到刚保存的模板。

「从用户作品导入」另需 `admin.generations` 权限：只导入已完成的直接图片/视频生成结果和允许公开的输入，保存为草稿；同任务重复导入返回已有模板。不复制私人参考素材、源用户身份、供应商报文或 Skill 内部指令。导入按原任务模型记录读取实际 modelKey，不把显示名称当作模型 ID。超过模板素材数量限制的作品会明确拒绝导入，避免静默删减原配方。导入保留图片生成数量及视频时长，兼容数值秒数和创作台的带 s 时长（含小数）。导入后需运营补全配方、素材要求、署名，视频另需封面，再发布。

内置6个图片示例覆盖黏土、纸艺、电影肖像、东方绘画、换装及产品广告。另有2个视频分镜封面草稿，确认配置后可仅使用封面上架，视频预览选填。示例重启不覆盖运营修改，不复活已删除内容。升级仅替换与旧内置文案完全一致的上传说明，去掉要求额外输入描述的文字；运营自行填写的说明保持不变。

另补充用户提供的[门店与食品厂20套内容](store-food-template-pack.md)，启动时导入为视频灵感草稿。没有封面和示例成片，可用新增的AI封面按钮补齐封面，试做确认配置后上架；视频预览选填。支持最多16个图片位置（仍受模型上限限制），`requirements.optionalImages` 指定从1开始的可选位置；可选图片配方用 `{{image:N}}` 固定绑定用途，生成时在后端按实际上传顺序编号。

## 按模型配置输出参数

视频提示词以「【生成视频：30秒｜9:16】」或「生成视频：30秒｜9:16」开头时，会自动补齐未设置的时长和画面比例。只读取开头，正文里提到的其他时长不会影响参数。开头为30秒且未手动指定模型的模板，默认匹配已上架、正常并兼容素材/规格/计费配置的 Seedance 2.5（兼容模型名称及 seedance-2.5 / seedance-2-5 形式的模型键）；匹配不到会明确提示，不自动缩短视频或改用其他型号。管理员已有的模型与参数选择保留。

已有未配置模板打开编辑器时也会填充；新建或粘贴提示词会触发同样逻辑。模型匹配复用不收费的配置检查；保存草稿会持久化匹配到的模型和参数，模型暂不可用仍允许保存草稿。前后端须一起更新，后台原始模板内容不会被批量覆盖。

视频自动填充默认使用720p，不再取清晰度列表首项。再次点击单条或批量「填充并上架」时，清晰度为空或480/480p（不区分大小写）的模板会更新为720p；已设1080p、4K等其他清晰度保留。即使模板已上架，也会更新旧的480p配置。所选模型必须支持720p及对应价格，否则该条保留原配置并提示原因。普通手动保存和已有作品不会被自动修改；填充不生成、不扣积分，用户之后生成按新清晰度正常报价。刷新已上架模板时，请将列表状态选为「全部状态」或「已上架」，不要只筛草稿。

视频模板编辑器的「自动填充并上架」按钮会校验封面、素材要求、模型与参数，通过后保存并将状态改为已上架；失败保留表单且不写入，仍可用普通「保存草稿」暂存不完整内容。列表切换到视频后，可点击「批量填充并上架」，按当前类型、分类、状态和搜索条件跨分页处理（单次最多200条）。每条在事务中读取最新配置，校验成功后一起写入模型、输出参数及上架状态；不改提示词、封面或使用次数。即使模型与参数早已填好，只要还是草稿也会正常上架。缺少封面、模型不可用或规格不匹配的保留原状态并列出原因，不影响其他模板。已经配置好的无开头模板也可正常校验上架，不会仅因为缺少识别标记而跳过。

批量接口的 `publish: true` 明确表示上架，省略或为 false 时仍兼容原来的仅填充保存。结果区区分「已上架」「已跳过」「未完成」；前端若收到旧后端仅保存的响应，会提示更新后端，不能把已保存当成已上架。重复操作跳过已上架且配置相同的模板；请求中断后可重试。整个过程不创建生成任务、不扣积分。

编辑器保存时携带打开时的上架状态。若其他操作已改变状态，旧表单不能把刚上架的模板悄悄改回草稿（或重新上架刚下架的模板），会提示重新打开确认并保留当前输入；数据库更新也核对状态，避免读取之后发生的并发修改被覆盖。单条与批量上架均接受已配置完整但没有规范开头的模板。成功上架的模板会离开草稿筛选，切换「上架状态 → 已上架」即可查看。

若多条模型管理记录共用同一个上游模型标识，模板会保存所选记录的ID，检查、报价、扣分和执行均沿用这条记录；停用后不会退回另一条同标识记录。编辑器也用独立选项区分这些模型，避免显示的是一个配置、实际保存或计费却用了另一个。数据库写入结果无法确认时提示刷新核对后重试，不断言本条一定没有保存。

后台参数区与创作台共用 `model-generation-options.mjs`，读取同一模型配置：

- 图片：已配置的比例、分辨率、质量；生成数量遵循模型数量范围及隐藏数量开关（上游批量上限4张）。
- 视频：已配置的比例、清晰度、时长，不展示图片质量与批量数量。
- 未配置的字段不显示自由输入框，也不发给生成服务；只有默认参数时明确提示。自动模型通过「检查生成配置」解析后显示对应参数。
- 切换模型保留兼容选项，删除不适用的旧选项；视频时长保留原值，不支持时明确提示，避免完整分镜被悄悄缩短。切回自动选择保留模板规格。空选项使用模型配置首项；分辨率、时长的可选项按数值排序。编辑器将界面所示的默认值一并提交，避免公开模型接口的时长排序与数据库原始顺序不同而改变生成规格。
- 用户端仍只提交上传素材 ID，模型、提示词、比例、分辨率、质量、数量、时长由后端模板填入。示例封面、示例视频不作为用户参考素材。
- 图片批量沿用创作台计费和生成行为，报价包含数量；结果页可切换各张结果并分别下载，原文件和放大入口始终指向当前选中项；再次生成从第一张结果开始。供应商可能少于请求数量返回，页面按实际结果展示，不伪造缺失图片。

## 复用新热点的运营方式与边界

单步图生图、图生视频、首尾帧或多模态参考的效果：先在创作台用几组不同素材验证配方 → 从成功作品导入（或复制相近模板） → 修改名称/封面/视频示例、后台提示词、素材角色 → 检查配置 → 上架 → 在用户页确认上传体验。

目前没有「粘贴抖音链接自动还原模板」。模板成片仅用于预览，不会自动作为生成参考；需要用户视频/音频的配方必须明确配置相应上传位置。后台统一预置动作视频/背景音乐、自动多镜头剪辑、字幕与卡点合成不属于本模块现有能力。需要这些能力的热点不能仅换封面、提示词就承诺用户一张照片完整复现。

## 部署与验证

仅修改 `flowingLight`，本次不改 `flowlight-en`。先更新主站后端，再更新主站前端；旧创作台前端依赖公开提示词，因此不能长期混用旧前端与新模板接口。无新增环境变量，无额外服务，继续使用已有 `studio_template` 数据表、上传、模型和积分体系。后端自动迁移新增 `input_labels` 列，仅为尚无此配置的旧内置样例补齐用途名称；运营自定义或明确清空的名称不被重启覆盖。

- 公开列表/详情：`GET /api/studio-templates`、`GET /api/studio-templates/:id`，只返回已上架内容与安全字段。
- 配置预览：`GET /api/ai/template-setup/:id`，公开返回实际规格、基础积分和素材大小限制；无素材时不核算参考视频附加费，不签发可执行报价令牌。
- 询价：`POST /api/ai/template-quote`，需登录，参数为 `{ templateId, input: { imageIds, videoIds, audioIds } }`。
- 有固定可选图片位置时，`input` 额外传 `imageSlots`，与 `imageIds` 一一对应；缺少必填、重复或越界位置在报价/扣费前拒绝。没有可选位置的旧模板维持原请求格式。
- 生成：`POST /api/ai/generate`，保留已有鉴权与幂等逻辑，额外传入 `templateId`、`templateQuote` 及报价返回的 handler/modelId。
- 后台维护：`/api/admin/studio-templates`；草稿配置检查为 `POST /api/admin/studio-templates/check`；来源查询/导入仍为 `/sources`、`/from-task`。
- 旧点击计数接口 `POST /api/studio-templates/:id/use` 已移除；实际受理任务负责计数。

服务端用例覆盖公开配方隔离、模型参数与费用变化、素材归属/类型、重复请求、下架后的任务恢复、音视频参考、预览规格与正式报价一致性、用途名称迁移。前端用例覆盖上传位置、替换失败保留、过期/失效草稿、账号与素材结构隔离、筛选返回、积分失败、断网重试、附件下载、后台维护及移动布局。浏览器用例使用模拟 API，不产生实际供应商生成或扣费。

本轮运营回归补充：六种生成模式通过真实服务层、数据库事务和模拟供应商验证素材顺序与实际扣分；上架校验、导入模型标识、超限导入、独立复制与未保存退出保护均有回归覆盖。参考视频时长变化会在扣费前使原报价失效；供应商失败退款和失败任务幂等恢复也已验证。尚未使用生产供应商生成来验证具体模板的视觉还原率。

深入回归补充：使用本地 HTTP 模拟上游，穿过真实 relay provider 和序列化，验证图生视频的模型、提示词、用户图片、比例、清晰度及 4.5 秒时长完整发送，收费与报价一致。传输层保留模型配置的小数秒数，不再截断为整数。数值形式的旧时长配置也保留为可选项。未使用生产供应商或真实付费素材生成来判断实际成品效果。

## AI 生成模板封面

编辑弹窗的「封面图片」区域提供「AI 生成封面」。默认根据模板标题、分类和介绍形成无字的封面示意图描述，不复制私有生成配方或用户参考图片。面板选择可用文生图模型，优先全局图片主模型，显示按实际默认画质/分辨率计算的预计积分；点击生成按当前管理员账号正常扣分，失败沿用已有退款逻辑。

任务复用现有幂等生成、生成记录与账号隔离的恢复机制。提交结果不确定时只检查原任务，不创建新的付费任务。收起面板仍会继续查询；成功后自动填入封面地址并更新预览，明确提示尚未保存，保存模板后对外生效。如果期间手动修改了封面或模板名称，则保留修改，展开面板后可点击「采用这张封面」。旧版本恢复记录没有原封面信息时只自动填入空封面。再次生成会产生新消耗。

新建模板点击「保存草稿并制作封面」时，先创建独立草稿 ID，再打开生成面板；保存草稿本身不调用图片模型或扣积分。每个模板、每个账号使用独立任务恢复记录。尚未保存的封面在刷新后重新编辑模板即可恢复，无需再次点击生成；仅在该图片实际保存成功后清理恢复记录。账号变化时重置未保存的编辑表单，避免沿用上一个账号的封面状态。恢复时原图片模型已不可用则明确提示重新选择，已有结果仍可回填，不会静默切到其他模型重新收费。

视频模板上架只要求有效封面及正确生成配置，不再强制视频预览。有真实视频预览时继续播放；没有时仅展示封面，明确提示「封面示意，尚无视频成片预览」。没有批量自动生成20张封面的后台任务，本次开发也未调用真实付费模型。
