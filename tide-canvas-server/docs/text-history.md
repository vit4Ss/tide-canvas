# 文本模型历史上下文

- 普通聊天（流式和非流式）、画布助手、技能文本调用及 Agent 的会话上下文，最多携带最近 **3 条历史消息**。用户消息、助手回复各算一条，不是 3 轮。
- 本次输入、当前附件和系统/技能指令另计。首次对话没有历史时只发送当前请求。原本单次执行、未提供会话历史的工具维持单次执行。
- 普通聊天停用自动压缩，不再注入既有摘要。`summary_upto_id` 不限制最近消息查询；旧摘要和完整聊天记录继续保存，不做删除。历史查询只取当前请求消息 ID 之前的 3 条，当前输入单独追加；图片和文件类型也不会漏掉本次输入或覆盖历史消息，重试不会读入后来追加的消息。
- 画布 Agent 自动引用的历史结果素材，与最近 3 条有效历史消息使用同一个窗口；当前主动选择的画布素材和附件另计。
- 上下文 token 用量只估算最近 3 条历史文本，发送前加上本次输入校验；不再累计整段聊天。`llm.contextTokenLimit` 仍控制这个窗口的文本估算上限。附件和系统指令不属于此估算，实际模型仍有自己的上下文限制。
- `llm.historyLimit`、`llm.compressAtTokens` 为旧配置，不再扩大历史窗口或触发压缩。管理页对旧键显示停用说明。
- 限制在后端执行时生效，旧客户端或旧任务传入较长历史也只读取末尾 3 条。旧请求快照保持原样以保证幂等重试，模型发送范围单独截取，不修改原始记录或再次扣费。
- 技能历史仅从 `input.messages` 进入 Agent 上下文，默认参数和 `input.parameters.messages` 不会再额外追加一份历史。
